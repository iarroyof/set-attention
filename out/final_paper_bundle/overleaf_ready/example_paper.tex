\begin{abstract}
We study a causal set-dictionary language model in which tokens are pooled into
causal dictionary atoms, atoms interact through exact dense set attention, and
tokens read back a routed span through an \texttt{anchor\_span} residual.  The
active model is multiresolution: routing heads are split between fine atoms
$(w,s)=(2,1)$ and coarser atoms $(4,2)$, with separate banks, set stacks, and
routers whose outputs are concatenated before prediction.  This gives a
constant-factor score-memory allocation problem inside the exact-dense
quadratic family rather than a subquadratic attention claim.

On WikiText-2, a corrected five-seed exact-dense matrix shows that a small
coarse allocation is the most useful set operating point in the larger
supported islands.  The b25 row, with six fine and two coarse heads, improves
the mean PPL--peak-VRAM frontier relative to both the matched dense token
baseline and the all-fine set endpoint at L2048/B4, L3584/B3, L3584/B4, and
L4096/B3.  At the L4096/B4 memory boundary, token, all-fine, and b25 are
censored by feasibility, while b50 remains trainable with comparable
perplexity to the longer-context frontier rows.  Theory formalizes the
executed multigroup \texttt{anchor\_span} model, proves the contextual path
through the routed span, gives the direct-sum routing-capacity law, and derives
the exact-dense score-memory coefficient.  Mechanism claims about associative
recall are deliberately left to registered AR-hit and MQAR probes.
\end{abstract}

\section{Introduction}

Attention is the dominant primitive for sequence modeling, but token-to-token
attention couples modeling capacity to pairwise score tensors.  We study a
different exact-dense allocation: instead of sparsifying token attention, a
causal set-dictionary model first pools tokens into dictionary atoms, processes
those atoms with exact dense set attention, and routes processed atoms back to
tokens.  The question is not whether this changes the asymptotic class.  In
the branch studied here it does not: exact dense set attention is still
quadratic in the number of atoms.  The question is whether changing the atom
resolution gives a useful quality--memory frontier under a fixed model shape
and matched dense token baseline.

The active model uses two atom resolutions in parallel.  Fine heads use
overlapping two-token atoms with stride one; coarse heads use four-token atoms
with stride two.  Each resolution owns its own bank, pooling operator, set
stack, and router.  The routed head outputs are concatenated before the
language-model head, while the \texttt{anchor\_span} residual preserves only a
thin token identity carrier and forces contextual prediction through the routed
span.  The all-fine endpoint b0 is therefore not token attention; it is a
set-mediated high-resolution control.  The all-coarse endpoint b100 is the
opposite boundary.  Interior rows b25, b50, and b75 ask whether a mixture of
resolutions can be better than either endpoint.

Our main empirical result is that the useful operating point is interior in
the larger exact-dense islands.  In a corrected five-seed WikiText-2 matrix,
b25 is the best set row by mean perplexity and uses less peak training VRAM
than both token attention and b0 at L2048/B4, L3584/B3, L3584/B4, and
L4096/B3.  The confidence intervals still require a cautious statistical
reading, but the PPL--memory direction is coherent across these larger
islands.  At L4096/B4, where token, b0, and b25 are censored by the registered
exact-dense feasibility boundary, b50 is the first moderate-blur row that
trains.  Thus the result is not a universal token-attention dominance claim:
shorter islands still favor dense token attention.  It is a more specific
allocation claim about exact dense multiresolution set dictionaries.

The accompanying theory is code-faithful to this branch.  We prove that
history dependence in the \texttt{anchor\_span} model factors through the
routed span, that multigroup routing has a direct-sum capacity law over tagged
fine and coarse candidate fibers, and that the exact dense score-memory
coefficient decreases linearly with the coarse-head fraction up to lower-order
finite-length terms.  These are structural and conditional results.  They do
not prove subquadratic scaling, token equivalence of b0, or that coarse heads
carry long-range associative recall.  Those mechanism questions are separated
into registered AR-hit and MQAR probes.

The rest of the paper is organized as follows. Section~\ref{sec:model-overview}
defines the causal multiresolution set-dictionary model.  Section~\ref{sec:main-theory}
states the compact structural results, with full proofs in the appendix.
Section~\ref{sec:results} reports the exact-dense WikiText-2 frontier and
diagnostics.  The appendix gives notation, code correspondence, provenance,
and deprecated legacy-material disposition.

\section{Related Work}
Prior work on structured and efficient alternatives to token-to-token attention can be organized into several overlapping themes. One line constrains token-to-token interaction directly through sparse or structured patterns such as locality, top-$k$ selection, or other restricted connectivity rules. Another line seeks linear or low-rank approximations that preserve the token-level attention interface while reducing the cost of dense pairwise interaction. These approaches are closely related to the efficiency motivation of this paper, but they typically treat the attention map itself as the main object to sparsify, approximate, or compress.

A second line of work changes how attention information is composed or aggregated rather than only changing the score kernel. LASER and DCFormer are examples within this broader design space: both explore departures from standard attention by modifying how information is organized inside the architecture, including mechanisms that alter head interaction or internal aggregation structure. We use the term \emph{routing} for our own explicit token-to-set assignment distribution; prior non-MoE transformer variants are better understood as inducing routing-like information flow rather than as implementing the same explicit routing module. The key difference is that our construction makes set formation, pooling, and routing explicit architectural stages, with bank topology entering as a first-class structural object rather than as an implicit property of an attention mask or a head-composition rule.

A third line emphasizes deployment setting or modality. Ripple Attention illustrates this perspective by tailoring attention structure to vision workloads, where the practical constraints and useful inductive biases differ from those of autoregressive language modeling. More broadly, this literature shows that efficient attention design is often shaped by hardware considerations, modality-specific structure, or the need to preserve strong baseline behavior under restricted interaction budgets.

Our paper differs from these lines of work in both representation and analysis.
Instead of approximating token-to-token attention directly, we study exact-dense
set-mediated token interaction through explicit bank topology, probabilistic
pooling, set-level processing, and routing distributions back to token space.
The current evidence focuses on the dense multiresolution setting because it is
the branch for which matched token/set controls, applied seeds, and diagnostics
are complete.  Sparse and landmark variants from earlier development are
historical provenance, not active evidence for the claims in this paper.

\section{Model Overview}
\label{sec:model-overview}

The active architecture in this paper is the code path implemented by
\texttt{SetOnlyLM} with multiresolution enabled, exact dense set backends,
\texttt{candidate\_fiber=endpoint\_window}, \texttt{output\_residual\_mode=anchor\_span},
disabled token MLP, disabled trained anchor, and disabled multivector basis.
The computation is
\[
\begin{aligned}
x_{0:L-1}&\longrightarrow h^{(0)}_{0:L-1}
\longrightarrow \{z^{0,g}\}_{g\in\mathcal G}
\longrightarrow \{z^{K,g}\}_{g\in\mathcal G}
\longrightarrow r_{0:L-1}\\
&\longrightarrow \operatorname{span}_{0:L-1}
\longrightarrow f_{0:L-1}
\longrightarrow \ell_{0:L-1}.
\end{aligned}
\]
The group set is $\mathcal G=\{\mathrm f,\mathrm c\}$ for mixed rows, with
fine and coarse topologies
\[
(w_{\mathrm f},s_{\mathrm f})=(2,1),\qquad
(w_{\mathrm c},s_{\mathrm c})=(4,2).
\]
Uniform endpoints are represented by keeping only one of these groups.  Routing
heads are partitioned as
$\bigsqcup_{g\in\mathcal G}\mathcal U_g=\{1,\ldots,H\}$, with
$H_g=|\mathcal U_g|$ and $\sum_gH_g=H$.

For a token sequence $x_0,\ldots,x_{L-1}$, the code first forms the thin anchor
\begin{equation}
\label{eq:main-token-state}
h_t^{(0)}=e(x_t)+p_t .
\end{equation}
The general implementation may apply a token MLP before pooling, but all active
paper runs set \texttt{model.token\_mlp.enabled=false}; hence the pooled token
state is exactly $h_t^{(0)}$.  For each group $g$, the strict-past bank drops
partial trailing windows and has
\begin{equation}
\label{eq:main-bank}
M_g(L)=
\begin{cases}
0,&L<w_g,\\
\left\lfloor\frac{L-w_g}{s_g}\right\rfloor+1,&L\ge w_g,
\end{cases}
\qquad
a_m^g=ms_g,\qquad e_m^g=a_m^g+w_g-1,
\end{equation}
with set
\begin{equation}
\label{eq:main-bank-set}
S_m^g=\{a_m^g,\ldots,e_m^g\},\qquad m=0,\ldots,M_g(L)-1 .
\end{equation}
The endpoint-window candidate fiber used by the reported language-modeling
runs is
\begin{equation}
\label{eq:main-strict-past-candidates}
\mathcal C_t^g=\{m:\ t-w_g<e_m^g\le t\}.
\end{equation}
The optional \texttt{all\_past} diagnostic replaces this by
$\{m:e_m^g\le t\}$; it is not part of the main multiresolution matrix.

Each group pools its own bank:
\begin{equation}
\label{eq:main-pooling}
z_m^{0,g}=\mathcal P_g(\{h_j^{(0)}:j\in S_m^g\})
=\sum_{j\in S_m^g}\omega_{j,m}^g h_j^{(0)},\qquad
\omega_{\cdot,m}^g\in\Delta(S_m^g).
\end{equation}
The reported runs use soft-trimmed Boltzmann pooling,
$\omega_{j,m}^g\propto
\exp(-\delta_{j,m}^g/\tau_{\mathrm{pool}})r^{\mathrm{trim},g}_{j,m}$,
renormalized over $S_m^g$.  The pooled states are projected into a group stream
of width $D_g=D_{\rm set}H_g/H$; in the reported rows $D_{\rm set}=D=384$.

Each group has a separate stack $\Phi_g$ of $K$ exact dense set-attention blocks.
For one set-attention head inside group $g$,
\begin{equation}
\label{eq:main-set-score}
a_{ij}^{(h,g)}=
\frac{\langle q_i^{(h,g)},k_j^{(h,g)}\rangle}{\sqrt{d_a}}
+\gamma_{ij}^g+b_{ij}^{(h,g)}+m_{ij}^g,
\end{equation}
where $\gamma_{ij}^g$ is geometry bias, $b_{ij}^{(h,g)}$ is content bias from the
configured feature path, and $m_{ij}^g$ is the causal mask.  In strict-past mode
the mask permits source atom $j$ for target atom $i$ only when
$e_j^g\le e_i^g$.  The active backend is exact dense set attention,
\begin{equation}
\label{eq:main-set-dense}
\operatorname{SetDense}(Q,K,V)=\operatorname{softmax}(A)V,
\end{equation}
and produces processed atoms $z_m^{K,g}=\Phi_g(z^{0,g})_m$.
Sparse, landmark, and other backend variants are archived provenance, not active
evidence for the claims in this paper.

Routing is group-local.  For head $u\in\mathcal U_g$, the learned router uses
the current token state and the group descriptor $d_m^g$:
\begin{equation}
\label{eq:main-router-score}
q_t^{u,g}=W_{Q,r}^{u,g}h_t^{(0)},\qquad
k_m^{u,g}=W_{K,r}^{u,g}d_m^g,\qquad
g_{t,m}^{u,g}=\frac{\langle q_t^{u,g},k_m^{u,g}\rangle}{\sqrt{d_{\phi,g}}}.
\end{equation}
In the hashed-count path used by the current runs, $d_m^g$ is the group router
descriptor returned by the feature builder; hashed-count features also enter the
set-attention content bias.  Candidate masking sets non-candidates to $-\infty$
and optional top-$k$ masking keeps only retained candidates.  With
$\tau_{r,\mathrm{eff}}=\max\{\tau_r,\tau_{\min}\}$,
\begin{equation}
\label{eq:main-routing-probs}
\pi_{t,m}^{u,g}=
\operatorname*{softmax}_{m\in\mathcal C_t^g}
\left(\tilde g_{t,m}^{u,g}/\tau_{r,\mathrm{eff}}\right),
\end{equation}
where empty fibers produce the zero routed vector in the implementation.
The routed head and group outputs are
\begin{equation}
\label{eq:main-routed-head}
r_t^{u,g}=\sum_{m\in\mathcal C_t^g}\pi_{t,m}^{u,g}
\operatorname{slice}_{u,g}(z_m^{K,g}),\qquad
r_t^g=\operatorname{Concat}_{u\in\mathcal U_g}r_t^{u,g}.
\end{equation}
The multiresolution route is the concatenation of group routes followed by the
set-output projection:
\begin{equation}
\label{eq:set-dictionary-span}
r_t=\operatorname{Concat}_{g\in\mathcal G}r_t^g,\qquad
\operatorname{span}_t=W_o r_t .
\end{equation}
Here $W_o$ is the implementation's \texttt{set\_output\_proj}; it is the identity
when $D_{\rm set}=D$ and otherwise maps from set-state width to model width.

The active readout is \texttt{anchor\_span}:
\begin{equation}
\label{eq:main-anchor-span}
f_t=h_t^{(0)}+\operatorname{span}_t,\qquad
\ell_t=W_{\rm lm}f_t,\qquad
p(x_{t+1}\mid x_{\le t})=\operatorname{softmax}(\ell_t).
\end{equation}
There is no contextual token tower in this readout: with the token MLP disabled,
$h_t^{(0)}$ carries only current-token identity and position, while dependence on
$x_{<t}$ reaches the logits through the routed span $W_o r_t$.  The span-ablation
hook sets all of $r_t$ to zero, or one group route $r_t^g$ to zero, for
diagnostics.  The final exact-dense SD matrix optimizes the ordinary next-token
cross-entropy loss on these logits only; trained-anchor auxiliary losses are
disabled in those runs.

The blur fraction is the coarse-head fraction $H_{\mathrm c}/H$.  The final
matrix uses b0, b25, b50, b75, and b100, corresponding to $0$, $2$, $4$, $6$,
and $8$ coarse heads out of $H=8$.  Full implementation metadata and the code
correspondence are summarized in Appendix~\ref{sec:mrp6-code-correspondence}.



\section{Theory}
\label{sec:main-theory}

The formal analysis below is for the executed multiresolution set-dictionary branch: exact dense set attention, separate fine and coarse banks, endpoint-window candidate gather, token MLP disabled, trained anchor disabled, and \texttt{anchor\_span} readout.  We state four compact results here and give complete proofs, code correspondence, and legacy-label disposition in Appendix~\ref{sec:theory}.  These statements are structural or conditional; they do not assert a perplexity win, token-attention equivalence, subquadratic complexity, or an intrinsic OOM theorem.

\begin{theorem}[Contextual-path factorization]
\label{thm:main-contextual-path-factorization}
For two histories $x,x'$ with the same current token and position at $t$, the active \texttt{anchor\_span} model satisfies
\begin{equation}
\label{eq:main-contextual-path-factorization}
\ell_t(x)-\ell_t(x')=W_{\rm lm}W_o\bigl(r_t(x)-r_t(x')\bigr).
\end{equation}
Thus every dependence of the logits on $x_{<t}$ factors through the routed span $W_o r_t$.  Span differences in the kernel of $W_{\rm lm}W_o$ up to an all-classes logit shift are not observable from softmax probabilities alone.
\end{theorem}

\begin{theorem}[Direct-sum multigroup routing capacity]
\label{thm:main-multigroup-routing-capacity}
Let $\mathcal G$ be the set of resolution groups, $\mathcal U_g$ the routing heads in group $g$, $H_g=|\mathcal U_g|$, and $\mathcal C_t^g$ the group endpoint fiber.  If $\widehat\Pi_t$ is the routing matrix over the tagged disjoint union $\bigsqcup_g(\{g\}\times\mathcal C_t^g)$, then
\begin{equation}
\label{eq:main-multigroup-routing-capacity}
\operatorname{rank}(\widehat\Pi_t)=\sum_g \operatorname{rank}(\Pi_t^g)
\le \sum_g \min\{H_g,|\mathcal C_t^g|\}.
\end{equation}
The admissible assignment space is the product of group-local simplices.  Finite-temperature dot-product routers parameterize smooth subsets of this space; boundary Dirac laws are limiting cases, not generally finite-temperature realizations.
\end{theorem}

\begin{theorem}[Exact-dense score-memory coefficient]
\label{thm:main-exact-dense-memory-coefficient}
For sequence length $L$, batch size $B$, $K$ set-attention blocks, and group bank sizes $M_g(L)=\lfloor(L-w_g)/s_g\rfloor+1$, the active exact backend materializes
\begin{equation}
\label{eq:main-score-count}
A_{\rm score}(L,B)=BK\sum_g H_gM_g(L)^2
\end{equation}
score elements before masking.  For fine $(w,s)=(2,1)$ and coarse $(4,2)$ with coarse-head fraction $p$,
\begin{equation}
\label{eq:main-blur-coefficient}
\frac{A_{\rm score}}{BKHL^2}=1-\frac{3p}{4}+O(L^{-1}).
\end{equation}
This is a constant-factor change inside the exact-dense quadratic family.
\end{theorem}

\begin{theorem}[Conditional interior allocation]
\label{thm:main-conditional-interior-allocation}
Let $n$ be the number of coarse heads, $A(n)=(H-n)M_f^2+nM_c^2$, and $E(n)$ an abstract validation or approximation error under a fixed control tuple.  If $M_c<M_f$, then $A(n)$ strictly decreases with $n$.  If the marginal gains $G(n)=E(n-1)-E(n)$ are nonincreasing with $G(1)>0$ and $G(H)<0$, then $E$ has an interior minimizer.  A mixed allocation is Pareto-better than all-fine exactly when it has no larger error and strictly smaller score memory.  The premises are conditional and must be established empirically for any specific task.
\end{theorem}
\section{Results}
\label{sec:results}

\paragraph{Protocol.}
All active results in this section use the current set-dictionary branch:
exact dense attention for both token and set rows, WikiText-2, $D=384$,
$d_{\mathrm{ff}}=1536$, six layers, eight heads, ten epochs, learning rate
$10^{-4}$, disabled token MLP, disabled trained anchor, endpoint-window
candidate fiber, and \texttt{anchor\_span} readout.  Set rows split the eight
heads between fine atoms $(w,s)=(2,1)$ and coarse atoms $(4,2)$: b0 is
all-fine, b25 is six fine/two coarse, b50 is four/four, b75 is two/six, and
b100 is all-coarse.  Every populated cell below uses full WikiText-2 and
applied seeds $0,\ldots,4$.  Perplexity comparisons are made only within the
same sequence-length and native-batch island.

\subsection{Research History: How the Experiment Line Led Here}
\label{sec:results-research-history}

The results below come from an extended campaign in which each phase was
designed to answer questions the previous phase left open.  We record that
sequence here for two reasons: several design choices only make sense in
chronological order, and the campaign developed a small working vocabulary
that the rest of this section uses.  Terms are defined where they first
appear in this subsection; later subsections use them without further gloss.

\paragraph{Phase 1: the registered WikiText-2 matrix.}  The campaign began
with a pre-registered experiment grid on WikiText-2 language modeling:
\emph{registered} means the configurations, seeds, and stopping rules were
frozen before launch, and later analysis was not allowed to quietly redefine
them.  We call each configuration a \emph{row} (token attention, or one of
the set blur allocations b0--b100 defined in the protocol above), and each
fixed combination of sequence length and batch size an \emph{island},
because comparisons are only valid inside one.  A row that could not run to
completion under the registered implementation --- typically because it
exceeded GPU memory --- is \emph{censored}: recorded as missing rather than
assigned a bad number.  This phase produced the frontier results of
Sections~\ref{sec:results-sd-grid-final}--\ref{sec:results-claim-boundary}:
an interior blur allocation (b25) is usually the best set row, and heavier
blur extends the feasible region at the memory boundary.  What it could not
produce was mechanism evidence, because perplexity is dominated by local
context.

\paragraph{Phase 2: mechanism probes.}  To ask mechanism questions we used
\emph{probes}: small, single-purpose diagnostic runs outside the registered
matrix, designed to answer one question rather than to fill a comparable
matrix cell.  The registered MQAR probe (multi-query associative recall ---
retrieve a value seen earlier under a matching key) returned null: every row,
including token attention, stayed near chance, so recall specialization
could not be attributed to any part of the architecture.  A second recall
evaluation (natural repeated-token hits) is still pending and is reported as
such.  After Phase 2 we therefore knew the memory frontier was real but had
no evidence about what set states preserve from the distant past.

\paragraph{Phase 3: the LCA diagnostic.}  We built the LCA (long-context
aggregation) task to force exactly the question perplexity cannot ask: can
the model use information distributed across the \emph{whole} context
(\emph{global aggregation}), rather than the recent local neighborhood?
Synthetic sequences contain marker tokens spread over the context, and the
target is a bucketed count of them.  The task is generated deterministically
from the seed, and token and set rows share data, supervision, fixed
architecture settings, and optimizer-update budget, so any quality
difference is attributable to the attention path alone.

\paragraph{Phase 4: calibration and repair.}  The first LCA grid failed
instructively: token attention learned the task while every set row stayed
at chance.  The cause was the frozen routing configuration, not the
architecture: under the \texttt{endpoint\_window} \emph{candidate fiber}
(the rule deciding which set atoms a query is allowed to read), the
supervised final token could only reach the two atoms nearest its own
position.  Three configuration properties turned out to govern whether the
set path aggregates at all: \emph{reachability} (which atoms a query can
read), \emph{supervision density} (at how many sequence positions a training
signal is given --- only the final token in the frozen configuration, or
every position under \emph{prefix supervision}, where each position predicts
the count so far), and \emph{routing bandwidth} (how many atoms each query
may read --- 16 under the frozen \texttt{router\_topk=16}, or all of them
under \emph{full routing}, where top-$k$ pruning is disabled).  Repairing
these three properties moved the set rows from chance to near-token quality.

\paragraph{Phase 5: the memory frontier on LCA.}  With the repaired
configuration we re-measured the quality--memory frontier at
$L\in\{1024,2048,4096\}$.  Two lessons resulted.  First, the set row trains
more slowly than token attention, so a fixed short update budget can mistake
undertraining for a quality ceiling; we call this a \emph{budget confound},
and it is why rows are compared at matched and sufficient budgets.  Second,
the set row's memory advantage grows with context length, exactly where
token attention stops fitting in GPU memory.

\paragraph{Phase 6: a measurement correction.}  The first $L=4096$ runs
appeared to show that the set row overfits at scale: its final validation
score degraded when the budget was doubled.  This was an artifact of how we
measured.  Our default was \emph{endpoint-only validation}: evaluating
validation metrics once, at the final update.  A \emph{trajectory probe} ---
a run that also evaluates validation \emph{periodically} during training,
tracing the validation curve instead of a single point --- showed that the
$L=4096$ validation signal oscillates strongly throughout training, so a
single endpoint is a luck-of-the-phase sample rather than a trend.  The
apparent overfitting was a trough of that oscillation; we retracted the
corresponding internal report, and we now report $L=4096$ as the endpoint
together with the \emph{best-of-trajectory} value (the best validation score
observed at any periodic checkpoint).

\paragraph{Where the line stands.}  The frontier claim survives the
correction, with one honest caveat per island size: seed variance at
$L=2048$, and estimator instability at $L=4096$.  The open threads are the
seed stability of the $L=4096$ rows, the role of the constant learning rate
in the oscillation, and whether the aggregation operator itself (a
normalized average, where the task rewards a sum) is the next mechanism
worth changing.

The first pattern is that all-fine is rarely the best set-mediated operating
point.  Among the ten fully token-comparable islands, b25 is the lowest-PPL set
row in nine; the only exception is $L=1024$/B4, where b0 is lower than b25 but
token is lower than both.  b25 is also the best overall row in eight of those
ten islands: L512/B3, L512/B4, L1024/B3, L2048/B3, L2048/B4, L3584/B3,
L3584/B4, and L4096/B3.  Token remains the best-quality row at L512/B16 and
L1024/B4.  Thus the matrix does not say that set-dictionary attention
dominates token attention everywhere; it says that the mostly-fine mixed row
is a repeated interior optimum under several exact-dense operating conditions.
In the larger islands b25 also uses less reported peak VRAM than both token
attention and all-fine: for example, at $L=2048$/B4, b25 reaches
$916.4\pm27.1$ perplexity and $18117$ MiB versus token at $942.8\pm15.6$ and
$18633$ MiB; at $L=4096$/B3, b25 reaches $864.6\pm21.7$ and $35365$ MiB
versus token at $909.3\pm28.8$ and $37955$ MiB.  Many five-seed confidence
intervals overlap, so this is a mean quality--memory frontier result, not a
theorem or a settled universal superiority claim.  The direction is
nevertheless coherent: a small coarse allocation often improves the set
frontier relative to making all heads as fine as possible.

The second pattern is the expected quality--memory curve as blur increases.
b50, b75, and b100 usually move left on memory while moving upward in PPL.
The all-coarse row is valuable as a boundary condition, but it is not the
model we would choose for quality: its PPL is hundreds of points worse than
the interior rows in every island.  The interesting rows are the interior
allocations, especially b25 for supported comparisons and b50 at the largest
batch/length boundary.  This matches the exact-dense memory theorem's
coefficient story without claiming a new asymptotic class: blur reduces the
number of set--set scores materialized per coarse head, but the backend
remains dense inside each chosen set bank.

The third pattern is the capacity boundary.  At $L=4096$/B4, the registered
exact-dense token, b0, and b25 cells have no endpoint-valid corrected rows,
while b50 trains with $893.2\pm39.3$ perplexity and $41387$ MiB.  This is not
a direct token-vs-b50 PPL win, because the token endpoint is censored.  It is
instead a useful feasibility result: moving from b25 to b50 sacrifices some
fine resolution but moves the run into the feasible exact-dense region while
keeping quality near the best supported longer-context rows.  That behavior is
exactly what the multiresolution allocation view predicts should be possible
when score memory, rather than parameter count, becomes the limiting resource.

Finally, the short rows keep the claim honest rather than collapsing to one
simple story.  At $L=512$/B3 and $L=1024$/B3, b25 is the best-quality row in
the completed matrix, and b25 also wins the short L512/B4 island.  At
$L=512$/B16 and $L=1024$/B4, dense token attention remains the best-quality
row.  Thus batch and context cannot be treated as interchangeable memory
controls, and the paper claim is not that set-dictionary attention dominates
token attention everywhere.  The supported claim is more specific and more
interesting: under exact dense attention, an interior fine/coarse set
allocation can trace a better mean quality--memory frontier in several
operating islands and can extend the feasible region at larger context/batch
settings.

The figures are intentionally related but not redundant.  Table~\ref{tab:sd-grid-final-matrix}
is the numeric register.  Figure~\ref{fig:sd-blur-path-frontier} asks whether
the blur path forms an interpretable PPL--memory curve inside each fixed
$(L,B)$ island.  Figure~\ref{fig:sd-operating-regime-map} asks a different
question: which set rows beat the matched token row and by how much, including
the censored cells.  Figure~\ref{fig:sd-group-routing-diagnostics} then leaves
PPL/VRAM space and checks whether the configured fine/coarse groups learn
different routing regimes.  Figure~\ref{fig:sd-mechanism-allocation} finally
puts the frontier and route-removal probes in the same view, showing whether
the memory frontier is carried by the same group whose removal most damages
the model.  The overlap is therefore deliberate: each view reuses the same
registered matrix to answer a different research question.

\subsection{All-Fine Control Is Not the Optimum}
\label{sec:results-all-fine-control}

The b0 row is the relevant high-resolution control for this branch.  It is not
token attention: tokens still pool into causal dictionary atoms, the set stack
processes those atoms, and the language-model head reads the routed
\texttt{anchor\_span} output.  But it is the closest registered row to the
intuition that more fine resolution should approach the token baseline.  The
final matrix does not support a simple monotone version of that intuition.  At
most completed islands, b25 is better than b0 in PPL, and from $L=2048$
upward it is also cheaper in peak VRAM.  The pattern appears already in the
short rows ($943.7$ vs.\ $1040.0$ at $L=512$/B3, $933.4$ vs.\ $1015.7$ at
$L=512$/B4, and $969.2$ vs.\ $987.6$ at $L=1024$/B3) and becomes a clearer
quality--memory improvement in the larger rows: $916.4$ vs.\ $956.5$ at
$L=2048$/B4, $893.5$ vs.\ $913.4$ at $L=3584$/B3, $875.7$ vs.\ $894.9$ at
$L=3584$/B4, and $864.6$ vs.\ $898.5$ at $L=4096$/B3.  The two exceptions are
informative rather than embarrassing: L512/B16 shows that a large short-context
batch favors the token control, and L1024/B4 is the one island where all-fine
is the best set row even though token is still best overall.  Thus the active
evidence is not that the set model wins by becoming token-like.  The useful
operating point is usually interior: mostly fine heads preserve the detailed
routed prediction path, while a small coarse allocation changes the memory
coefficient and, empirically, improves the set frontier.

This distinction matters for reviewer interpretation.  If b0 were always the
best set row, the result would be a costly approximation-to-token story.  If
b100 were competitive, the result would be a coarse-compression story.  The
observed pattern is neither.  All-coarse consistently pays a large quality
cost, all-fine is usually not the optimum, and b25 is the stable quality point
in the main supported islands.  The set dictionary is therefore acting as a
multiresolution allocation, not merely as a degraded token attention surrogate.

\subsection{Blur Sweep and Capacity Boundary}
\label{sec:results-blur-capacity}

The blur sweep gives a compact view of the quality--memory curve.  Moving from
b0 to b100 reduces the number of dense set--set scores contributed by coarse
heads, and the measured peak-memory branch follows that pressure: b50, b75,
and b100 are generally progressively cheaper than b25 and b0 once the context
is large enough for score tensors to matter.  The short rows show why this is
not a one-dimensional memory story: L512/B16 favors token quality despite the
availability of all blur settings, and L1024/B4 favors token quality while b0
is the best set row.  Quality is therefore not monotone in blur.  b25 usually
gives the best PPL, b50 is the important memory-saving compromise, and
b75/b100 mark the quality-degraded side of the frontier.  This is the
empirical counterpart of
Theorem~\ref{thm:main-exact-dense-memory-coefficient}: the theorem explains why blur can
reduce the exact-dense score coefficient; the matrix shows where that
coefficient reduction remains useful rather than merely destructive.

The most concrete capacity result is $L=4096$/B4.  Under the registered exact
dense implementation, token attention, b0, and b25 have no endpoint-valid
corrected rows at this island.  b50, b75, and b100 do train, and b50 reaches
$893.2\pm39.3$ PPL.  We treat the missing rows as censored feasibility
observations, not as assigned losses, so this row is not a direct statistical
win over token attention.  Its role is different: it shows that a moderate
increase in coarse allocation can move the model across the observed memory
boundary while preserving a perplexity level comparable to the successful
longer-context frontier rows.

\subsection{Fine and Coarse Group Diagnostics}
\label{sec:results-group-diagnostics}

The group diagnostics explain why the mixed rows should not be read as a
single blurred stream.  Figure~\ref{fig:sd-group-routing-diagnostics} reports
the routing diagnostics as blur changes inside fixed context/batch islands,
with five-seed means and confidence intervals.  Columns separate context
length, the x-axis is coarse-head fraction, and batch is shown as a
sub-position around each blur tick: B3 to the left, B4 at the center, and B16
to the right.  This encoding avoids drawing artificial trajectories through
different contexts or batch sizes.  Endpoints are group-specific: the all-fine
b0 row contributes only the fine trace, and the all-coarse b100 row contributes
only the coarse trace.  Censored cells, such as the missing L4096/B4 b0/b25
rows, are left absent rather than assigned losses.
Effective range is the routing-probability-weighted mean distance
$|t-\operatorname{center}(e_m)|$ to the selected atom center.  Routing entropy
measures spread across the endpoint-window candidate fiber, and top-1
probability measures concentration on the strongest routed atom.  Across
contexts and batches, fine routing remains sharper and more local: its
effective range stays around the sub-token-to-one-token scale, its entropy is
lower, and its top-1 probability is higher.  Coarse routing consistently
occupies the broader, higher-entropy regime, with effective ranges near three
tokens and lower top-1 concentration.  Within-island blur slopes are visible
but secondary.  Adding coarse heads usually leaves the fine path concentrated,
while the coarse path becomes slightly more concentrated as it receives more
heads.  The labels ``fine'' and ``coarse'' therefore correspond to learned
routing behavior, not only to config metadata.

Route-removal ablations give the complementary picture.  Zeroing the fine
contribution usually hurts far more than zeroing the coarse contribution in
mixed rows: b25 fine-removal deltas are roughly $15$--$23$ thousand PPL points
across the main islands, whereas b25 coarse-removal deltas are near zero.
As the allocation moves toward b75, fine-removal deltas fall because fewer fine
heads remain, and coarse-removal deltas rise because the coarse stream now
carries more of the routed signal.  The coarse stream's value at b25 is
therefore subtler than direct replacement: its standalone ablation delta is
small, yet adding a small coarse group often improves b25 over b0 and reduces
memory.  This supports a complementarity interpretation.  Coarse heads are not
replacing the fine path; they supply a broader, higher-entropy routed summary
that changes the allocation enough to improve the frontier.

\subsection{Claim Boundary and Next Mechanism Tests}
\label{sec:results-claim-boundary}

The current results support an exact-dense multiresolution frontier claim:
moderate blur improves the mean PPL--VRAM frontier in the main supported
WikiText-2 islands, and heavier blur extends the feasible region at the
$L=4096$/B4 memory boundary.  They do not establish subquadratic scaling,
universal token-attention superiority, token equivalence of b0, or an
associative-recall mechanism for coarse heads.  Those stronger mechanism
claims are deliberately separated from the frontier result.  The registered
MRP-3 synthetic MQAR matrix completed all 18 primary rows, but every row stayed
near chance; the frozen b25 row reached mean query accuracy $0.000247$, far
below the prespecified $0.90$ support threshold.  This threshold is not a
state-of-the-art bar; these are small prototype models.  Its role is to decide
whether lag-conditioned group ablations can be interpreted as recall
specialization.  Table~\ref{tab:mqar-prototype-comparison} reports the
prototype comparison rather than hiding it behind the gate decision.  MQAR was
run across the same blur-resolution family at one synthetic context length
($L=2048$, batch 4), not across the full WikiText context grid.  Thus it can
ask whether the b0--b100 ordering reappears on a controlled recall task, but it
cannot by itself establish how that ordering changes with language-model
context length.

\subsection{From Perplexity to Global Aggregation: the LCA Diagnostic}
\label{sec:results-lca-task}

The frontier and null results above leave one mechanism question open.  Every
set row in the registered matrix ran the same frozen routing configuration:
\texttt{endpoint\_window} candidate fiber, \texttt{router\_topk=16},
\texttt{router.score\_mode=candidate\_gather}, and a final-token language-model
loss.  Perplexity is dominated by local context, so a failure of \emph{global}
aggregation would be invisible in it, and the only non-LM probe (MQAR) returned
null at chance.  After the registered matrix there was therefore no evidence
about what set states retain of information distributed across the whole
context, and no evidence about whether the memory frontier survives on a task
that requires such retention.  We built the LCA (long-context aggregation)
diagnostic to force exactly this question: synthetic sequences of length
$L\in\{1024,2048,4096\}$ contain marker tokens distributed across the context,
and the target is a bucketed count of those markers (a binary count bucket in
the registered configuration, so chance accuracy is $0.5$).  The task is
generated deterministically from the seed, token and set rows share data,
supervision, fixed architecture settings, and optimizer-update budget, and
models train on 20{,}000 generated examples.  LCA is a controlled diagnostic that complements the WikiText-2
perplexity matrix; it does not replace it, and we do not draw natural-language
conclusions from it.

\subsection{Calibration: Supervision and Routing Bandwidth, Not Aggregation per se}
\label{sec:results-lca-calibration}

The registered 36-row calibration matrix (token plus b0--b100, $L=1024$ and
$L=2048$, seeds $0,\ldots,2$, 2000 updates) produced a clean failure.  The
token control learns the task ($0.713\pm0.083$ mean accuracy at $L=1024$,
individual seeds $0.618$--$0.770$), while every set row stays at chance
($0.483$--$0.524$ across all blur allocations, both lengths, and all seeds).
The cause is topological, not statistical: under \texttt{endpoint\_window},
each query routes only to the roughly two set atoms adjacent to its own
position, so distant markers are unreachable from the supervised final token;
their information could only arrive by propagating through neighboring atoms
one layer at a time, and six layers of such local propagation cannot bridge
$L=1024$.  The paper's frozen
fiber is incapable of global aggregation by construction, which means the
WikiText-2 frontier was measured entirely inside a local regime.

Repairing reachability was necessary but not sufficient.  Switching to an
\texttt{all\_past} fiber is memory-infeasible in \texttt{candidate\_gather}
mode (the router materializes a $[B,H,T,C,d_\phi]$ tensor; that run exceeded
GPU memory on both hosts, which we record as a censored implementation
boundary rather than a scientific result).  Scoring densely instead
(\texttt{router.score\_mode=dense}, scores materialized as $[B,H,T,M]$ with
invalid entries masked) fits at $3216$ MiB with
\texttt{candidate\_count\_max=1023}, but the row still does not learn under
final-token-only supervision (validation accuracy $0.498$ versus $0.770$ for
the matched token seed).  Three probes (P1--P3) then localized the residual
deficit (Table~\ref{tab:lca-calibration-probes}).  P1, full routing
(top-$k$ opened to all $1023$ candidate atoms, \texttt{router\_topk=1023},
i.e.\ no pruning), reaches $0.827$: top-$k{=}16$ sparse selection
was discarding the many weak evidence paths that global counting needs.  P2,
prefix supervision (every position predicts its own prefix count), reaches
$0.787$ against a token control at $0.903$: final-token-only supervision was an
independent bottleneck that token attention tolerates, because its gradient
routes directly to all positions, and sparse-fiber set attention does not.
P3, which hands the model the true marker count as an input feature (an
oracle that bypasses representation learning), reaches $0.985$: when the
count is represented,
routing and readout solve the task, so the residual deficit lives in the
training-signal/routing interface rather than in an intrinsic inability of
set-dictionary attention to aggregate.  The combined configuration
(\texttt{all\_past} $+$ dense scoring $+$ full routing $+$ prefix supervision)
reaches $0.936$ on seed 0, apparently above the token control --- but a
three-seed follow-up showed this to be within seed-to-seed variation: token
$0.9443\pm0.0317$, b25 with full routing $0.8956\pm0.0407$, b25 with
top-$k{=}16$ $0.8171\pm0.0114$.  We apply the resulting lesson throughout this
section: no single-seed conclusions, and set rows carry higher seed variance
than token rows.

\subsection{The Memory Frontier on Long-Context Aggregation}
\label{sec:results-lca-frontier}

Table~\ref{tab:lca-frontier} reports the frontier under the repaired
configuration, using b75 (two fine, six coarse heads) as the set row.  The
choice of b75 is itself a result: a blur sweep at $L=1024$ over
$\{$b25, b50, b75, b100$\}$ found quality non-monotone in blur, with
b75 ($0.9233\pm0.0157$) above b50 $\approx$ b25 ($0.8956$--$0.8974$ means)
above b100.  Coarse atoms both shrink the $O(L^2)$ score tensor and pool
wider token spans, so counting evidence is gathered into fewer, larger
units, while the all-coarse row loses detail.
Note the inversion against the WikiText-2 matrix, where b25 was the interior
optimum: resolution and compression trade differently across task classes.

\input{tables/lca_frontier}

Three patterns matter.  First, the memory advantage is real and grows with
context length: $-12.5$\% at $L=1024$, $-21.1$\% at $L=2048$, and $-26.2$\% at
$L=4096$.  This is the memory-coefficient analysis of
Section~\ref{sec:theory} made concrete: blur
reduces the score-memory coefficient while the backend stays dense, and as $L$
grows the score term dominates total memory, so the b75/token peak ratio falls
toward its asymptotic value.  At $L=4096$ the token row peaks at $33746$ MiB,
which exceeds a 24\,GB GPU, while the
b75 row at $24910$ MiB (measured by a short 30-update admission run that
records peak memory without training to completion) nearly fits it;
$L=4096$ rows therefore ran only on a larger 48\,GB host.  This is the same
regime as the censored $L=4096$/B4 boundary of the WikiText-2 matrix: exactly
where dense token attention stops fitting.

Second, quality in the same regime as the token control holds at $L=1024$
and $L=2048$, but with higher
set-row variance.  At $L=1024$ b75 is within seed-to-seed variation of token
($0.9233\pm0.0157$ versus $0.9443\pm0.0317$).  At $L=2048$ an apparent quality
gap at 2000 updates (b75 seed 0 at $0.8158$ versus token $0.9440$) proved to
be mostly a budget confound: at 4000 updates the same seed reaches $0.9353$,
and the three-seed mean is $0.9078\pm0.0368$ at $-21.1$\% VRAM, with token
already saturated at $0.9438$.  The quality--memory advantage holds on
average but not for every seed (seed 1 reaches $0.8660$), and the set row's
seed standard deviation

$L$-insensitive throughout ($0.9443$, $0.9438$, $0.9407$ at
$L=1024,2048,4096$).

implementation.  A bandwidth sweep at b75/$L=1024$ over

4000-update budget, top-$k{=}256$ reaches $0.8099$ against $0.9353$ for full
routing (both seed 0), a genuine bandwidth loss.  Sparsity would have to move
into scoring itself to buy memory; we do not claim it does.

throughout training (b75 between $0.61$ and $0.93$; even token between

validation set, so any single endpoint is a phase sample of an oscillation,
not a trend.  The degraded extension endpoint was a trough; the trajectory
endpoint is a near-peak.  Two consistency checks anchor this reading: the
trajectory's evaluation at update 4000 reproduces the earlier 4000-update
endpoint bitwise ($0.838196$), and its training curve is bitwise-identical
to the earlier extension run through update 5000, diverging only when the
data loader re-shuffles the 20{,}000 training examples at the start of the
second pass over the data --- a draw whose outcome depends on the random
generator's state, which the periodic evaluations had shifted.  Under trajectory measurement the $L=4096$ picture
is the same matched regime as at shorter contexts: the b75 row reaches
$0.9319$ at its best point ($0.9269$ at the 8000-update endpoint) against
token's $0.9712$ best ($0.9603$ endpoint), a gap of about $0.03$--$0.04$ at
$-26.2$\% peak VRAM, with the set row's best validation losses occurring in
the 6000--8000 region --- no monotone degradation with budget.  Three
caveats stand: the $L=4096$ rows are single-seed; the oscillation itself is
unexplained (constant learning rate is the leading suspect, and both
families oscillate, the set row more); and same-seed runs are sensitive to
second-epoch data order, an additional variance source.  We therefore
report $L=4096$ as best-of-trajectory with the endpoint alongside, and we
do not claim quality parity there --- we claim the same matched-quality
regime with the widest uncertainty of the three islands.  We also note a
practical cost: by external launcher timestamps the $L=4096$ b75 run took
about $4.9$ hours per 4000 updates against $42$ minutes for token on the same
host, roughly $7\times$ slower; these are wall-clock launcher measurements,
not framework-internal timers.

\subsection{Updated Claim Boundary}
\label{sec:results-lca-claim-boundary}

The LCA campaign tightens the claim boundary of
Section~\ref{sec:results-claim-boundary} in four ways.  (i) The memory
frontier advantage is real on a task that requires global aggregation, and it
grows with context length ($-12.5$\% $\to$ $-21.1$\% $\to$ $-26.2$\%), exactly
where dense token attention becomes hardware-excluded; this is the regime in
which set attention must win if the frontier story is true.  (ii) The paper's
frozen endpoint-window/final-token configuration badly understated the set
path's aggregation ability: reachability, supervision density, and routing
bandwidth are configuration-level properties, and under the repaired
configuration the set path aggregates globally at all.  Configuration matters
as much as blur allocation.  (iii) Matched-regime quality holds at
all three context lengths: within about $0.02$--$0.03$ of token in mean
accuracy at $L=1024$ and $L=2048$ (with higher set-row seed variance and
overlapping intervals), and within about $0.03$--$0.04$ at $L=4096$ under
best-of-trajectory measurement, where the single-seed estimate and the
oscillating validation signal carry the widest uncertainty.  (iv) The
non-claims stand and gain one member: no subquadratic scaling (router scoring
is still dense), no universal token-attention superiority, no token
equivalence of b0, no associative-recall mechanism, and no benefit from
sparse top-$k$ routing, which is currently dominated by full routing at equal
memory.

The immediate next steps follow from the $L=4096$ oscillation finding: a
learning-rate-schedule probe (constant $10^{-4}$ is the leading suspect for
the oscillation), best-of-trajectory or averaged-checkpoint reporting in
place of bare endpoints, and $L=4096$ seeds 1--2 with periodic validation to
bound the estimator instability.  The operator question is motivated
independently: counting is a sum, but softmax routing computes a normalized
average, and the P3 oracle result ($0.985$) shows the task is solvable once
the count is represented, so a sum/additive-routing variant is the natural
mechanistic test.  A hybrid linear$+$sparse-retrieval branch may follow from
that diagnosis; if pursued it will be labeled explicitly as a new branch with
its own memory accounting, and never used to rescue the set-only claims
above.

\section{Conclusion}
The revised experiments establish a conservative empirical picture.  The
strict-past SKA implementation is causal, configurable, and memory-efficient at
long context, but matched token-attention controls remain stronger on
perplexity.  The capacity ablations rule out the simplest explanations that
the gap is merely due to too-small $d_\phi$, too-small set-state width, too
shallow set processing, insufficient anchoring signal, or too narrow a causal
candidate fiber.  The most defensible contribution is therefore a causal
set-mediated architecture and diagnostic analysis of when its topology,
pooling, interface width, and set-processing depth help or fail, rather than a
claim of perplexity dominance over matched token-attention baselines.

\section{Future Work}

\subsection{Routing Memory and Long-Context Priority}
\label{sec:future-routing-memory}

The VRAM audit changes the priority list.  The current problem is not mainly
extra memory from logging or diagnostics: the near-token overhead comes from the
active architecture and implementation path, especially the simultaneous token
and set streams, dense token-to-set routing tensors, and set-attention tensors.
Thus memory should be reduced by changing the active computation, not by
subtracting a measurement artifact from the reported values.  The clearest
implementation target is candidate-gather routing.  Under strict-past
Option--1, token $t$ only routes over its endpoint fiber $\mathcal C_t$, but the
current learned router still constructs dense $[B,H,L,M]$ score and probability
tensors.  A semantics-preserving implementation should gather the active
candidates into $[B,H,L,C_{\max}]$, where $C_{\max}$ is the maximum candidate
count in the batch, and scatter the routed context back to tokens.  This directly
attacks the audit finding while preserving the causal bank definition.  A second
implementation target is to use fused or memory-efficient kernels for routing
and set self-attention where the masks allow it, following the IO-aware lesson of
FlashAttention \citep{dao2022flashattention}.  This may reduce peak memory
without changing the mathematical model, although it does not by itself solve
the quality gap.

The more important scientific direction is to test settings that should favor a
set-mediated model.  The exact-dense multiresolution matrix above is
encouraging in this limited sense: moderate blur improves the mean frontier at
the larger supported islands, and b50 moves the $L=4096$/B4 setting into the
feasible region.  This is consistent with the broader long-sequence literature,
where the value of alternative attention mechanisms is clearest under
long-context memory pressure, sparse or routed computation, or compressed
memory rather than under short-context token-equivalent replacement
\citep{dai2019transformerxl,rae2019compressive,beltagy2020longformer,zaheer2020bigbird,roy2020routing}.  It is also aligned with latent and set bottleneck
architectures, which are usually trained around a compression interface rather
than evaluated only as a drop-in token-attention substitute
\citep{lee2019settransformer,jaegle2021perceiverio}.

\subsection{Set-Dictionary Span as a Diagnostic Branch}
\label{sec:future-set-dictionary}

Section~\ref{sec:model-overview} defines the current set-dictionary branch and
Figure~\ref{fig:set-dictionary-architecture} gives its computation graph.  The
diagnostic branch terminology is retained here only to explain earlier capacity
probes: those probes varied the candidate fiber, the trained-anchor auxiliary
target, and atom width while keeping the same \texttt{anchor\_span} readout
\eqref{eq:main-anchor-span}.  In all cases the contextual token representation
is the routed span $\operatorname{span}_t=W_o r_t$ from
\eqref{eq:set-dictionary-span}; the language-model head does not receive a
separate contextual token tower.

The earlier capacity probes also tested two causal candidate fibers.  The
endpoint-window fiber used by the main strict-past experiments is group-local:
\begin{equation}
\mathcal C_t^{g,\mathrm{win}}=\{m:t-w_g<e_m^g\le t\},
\end{equation}
where $e_m^g$ is the endpoint of atom $m$ in group $g$.  The maximal causal
fiber used in the \texttt{all\_past} diagnostic is
\begin{equation}
\mathcal C_t^{g,\mathrm{all}}=\{m:e_m^g\le t\}.
\end{equation}
Both are causal; \(\mathcal C_t^{g,\mathrm{all}}\) removes the local
candidate-count ceiling by allowing every sealed past atom to compete for each
token.

The trained-anchor capacity probe used an auxiliary objective that is not part
of the final SD matrix.  It gave the span a predictive target without using
that target at inference: a shallow causal pre-encoder produced $h_t^\star$ and
had its own next-token CE head.  During those diagnostic runs only, the
objective was
\begin{equation}
\label{eq:set-dictionary-anchor-loss}
\mathcal L
=\mathcal L_{\mathrm{CE}}
+\lambda_{\mathrm{pre}}\mathcal L_{\mathrm{CE,pre}}
+\lambda_h\,\frac1L\sum_{t=1}^L
\left\|\operatorname{LN}(\operatorname{span}_t)
-\operatorname{sg}\!\left(\operatorname{LN}(h_t^\star)\right)\right\|_2^2,
\end{equation}
where $\operatorname{sg}$ stops gradients through the anchor target.  The
pre-encoder and its head are training-only and are excluded from inference
accounting.  This auxiliary loss was not used for the exact-dense
multiresolution results in Section~\ref{sec:results-sd-grid-final}; those rows
use ordinary next-token CE with trained anchor disabled.  The guard matters for
the diagnostic ladder only: if $h_t^\star$ is not trained, the anchor is a
random target and the reconstruction diagnostic is uninterpretable.

The related experiments are grouped in Table~\ref{tab:sd-capacity-ladder},
Figure~\ref{fig:sd-capacity-ladder}, and
Table~\ref{tab:sd-width-comparison}.  They test three increasingly direct
interventions: a valid trained anchor, the maximal causal fiber, and
over-provisioned dictionary atoms wider than the matched token baseline.

very large throughout, so the anchor is not silently solving the task.  The

atom is formed by compressing token states into a finite set summary, later
routing, anchoring, and atom widening cannot recover all token-resolution
predictive detail.  This is a publishable mechanism result, consistent with
the paper's candidate-count, concentration, and transport framing.

\subsection{Compressive-Memory Evaluation and Compression Baselines}
\label{sec:future-compressive-memory}

The set-dictionary ladder in Section~\ref{sec:future-set-dictionary} suggests
that the next research direction should not be another short-context capacity
sweep.  The better framing is compressive memory: set states should be judged
as learned summaries of past context under explicit memory budgets, not only as
a drop-in replacement for token attention at $L=512$.  A useful follow-up
should therefore pair long-context evaluation with matched compression
baselines.  Examples include sliding-window token attention with the same peak
VRAM, recurrent or chunked memory with the same retained-state budget,
landmark-token baselines with matched memory, and retrieval-style baselines
that expose how much information survives in a compact state.  The key metric
should be a quality--memory frontier over increasing $L$, with per-family
token controls and set-mediated models compared at fixed training budget and
fixed peak memory.

This reframing also clarifies the role of the current negative results.  The
trained-anchor, \texttt{all\_past}, and doubled-width probes show that simply
giving the router more candidates, a predictive target, or wider atoms is not
enough in the short-context token-replacement setting.  But those failures are
precisely the diagnostics one wants before treating the set bank as a
compressed memory.  Future experiments should ask whether the same bank gives a
better long-context tradeoff when the baseline is an explicit compression
system rather than unconstrained dense token attention.  The most informative
protocol is a fixed-VRAM long-context suite: evaluate continuation,
needle-style retrieval, associative recall, and long-document language
modeling while comparing against token-window and compressed-memory baselines
at the same memory budget.

We therefore propose four targeted follow-up experiments after the routing
memory fix.  First, use a compression curriculum: start from nearly
token-equivalent banks such as $(w,s)=(1,1)$ or $(2,1)$ and gradually move to
$(4,2)$ and $(8,4)$, instead of asking the model to learn language modeling,
routing, pooling, and compression simultaneously.  Second, train with a matched
token-attention teacher, adding logit distillation and optionally hidden-state
matching so that set states learn which predictive information must survive
compression.  Third, evaluate under a fixed-VRAM long-context protocol at larger
$L$, comparing exact token controls against b0, the frozen b25 row, and the
all-coarse boundary row under the same backend.  Fourth, because the current
matrix suggests that interior blur helps under memory pressure, add an
auxiliary compression objective: reconstruct teacher hidden states, token
windows, or next-token distributions from the set states before or alongside
the causal LM loss.

	Two architectural variants are also worth isolating.  The first is activation
	sharing: compute routing queries from a lightweight descriptor rather than
	keeping a full token stream solely for routing, checkpoint or recompute token
	states that are routing-only, or drop token activations after pooling except at
	positions whose candidate fiber is empty.  These variants are more invasive than
	candidate-gather routing and may affect quality, but they address the audit
	observation that the singleton limit carries both token and set states.  The
	second is hybrid attention: use token attention in some layers and set attention
	in others.  This is closer to practical long-context systems, where local/global
	sparse attention, recurrent memory, or retrieval often complements rather than
	fully replaces token attention
	\citep{dai2019transformerxl,beltagy2020longformer,wu2022memorizing}.
	
	\subsection{Hybrid Token--Set Bridge Pilot}
	\label{sec:hybrid-token-set-pilot}
	
	We ran a small hybrid pilot to test whether preserving token-attention layers
	can bridge fine-grained token information through a set-mediated stack.  The
	hybrid model uses one shared token hidden stream $X\in\mathbb R^{B\times L\times
	d}$: token layers and set layers both update this same sequence, rather than
	forming disconnected token and set towers.  A token layer therefore transports
	ordinary token-attention features forward to later layers, while a set layer
	pools the current shared stream into strict-past endpoint sets, processes those
	sets, and routes the resulting context back to token positions.  This shared
	stream is the intended information bridge.  It does not make the architecture
	equivalent to token attention, because positions with nonempty candidate fibers
	still pass through pooling, set attention, routing projections, and the
	\texttt{empty\_only} output policy.

	Table~\ref{tab:hybrid-token-set-pilot} shows a clear negative result, but the
	diagnostics make it informative.  Keeping more token layers helps monotonically
	among the tested patterns: TTTTSS is better than TSTSTS and TTSSSS, which
	supports the bridge intuition.  However, even the best hybrid row remains much
	worse than both the sparse token baseline and the single-stack sparse set model
	at comparable compression.  This is not simply a candidate-count failure.  The
	single-stack sparse set row at $(w,s)=(4,2)$ has mean candidate count about
	$1.98$ and reaches PPL $1438.5$, whereas the hybrid TTTTSS uses the same
	near-2 set topology in one set layer plus an $(8,4)$ layer with mean candidate
	count about $1.96$, yet degrades to PPL $2393.4$.  Repeated compression through
	multiple set layers appears more damaging than one compressed set stack, even
	when token layers provide a shared-stream bridge.
	
	The broader architecture evidence points in the same direction.  Historical
	capacity ablations are now deprecated as active evidence, but they remain
	useful provenance: widening $d_\phi$, widening set states, or increasing
	set-stack depth did not reliably close the older model's gap.  The current
	MRP-1 result points instead to allocation across fine and coarse groups.  The A7
	quality--efficiency frontier shows that compressed set rows can reduce VRAM but
	pay large PPL gaps, while the A8 $L=8192$ linear follow-up shows a strong memory
	benefit without a matching quality recovery.  The hybrid pilot adds one more
	constraint: token/set layer mixing alone does not solve either side of the
	tradeoff.  It also does not create a memory win in this implementation: peak
	VRAM is essentially the same as sparse token attention because the model still
	carries the token stream, set states, and dense token-to-set routing tensors.
	
	The minimal promising path is therefore not ``add set layers to a token model''
	by itself.  It should combine hybrid placement with changes that target the
	measured failure modes.  First, candidate-gather routing should remove dense
	$[B,H,L,M]$ routing tensors; this is mainly a memory fix, but it restores the
	purpose of compression.  Second, the set layers need a training signal that
	tells them what token-level information must survive compression, such as a
	compression curriculum, logit distillation, or hidden-state reconstruction from
	a matched token teacher.  Third, if hybrid layers remain useful, they should
	include explicit residual or cross-layer bridges from early token states into
	later set layers, so compression is not forced to preserve all predictive detail
	through a single routed context.  The observed ordering
	TTTTSS $<$ TSTSTS $<$ TTSSSS in perplexity suggests that a still milder
	pattern, such as a late single set layer or a gated set residual added on top of
	token attention, is a more plausible next test than deeper set-heavy stacks.

\subsection{Long-Context Data and Memory Tasks}
\label{sec:future-long-context-memory-tasks}

Finally, the larger-data question should be tested, but not treated as the first
fix.  The 30-epoch convergence panel argues against ``just train longer'' as the
whole explanation, yet the set path has additional routing and compression
machinery that may be undertrained on WikiText-2 scale.  A serious follow-up is
a fixed-token-budget run on WikiText-103 or a fixed OpenWebText subset, using a
compact grid of dense, sparse, and landmark token baselines against matching SKA
families at $(w,s)\in\{(1,1),(2,1),(4,2),(6,2),(16,8)\}$.  This would test whether the
observed compression loss is fundamental under the current architecture or a
small-data/training-regime artifact.

Set states should also be evaluated directly as compressed memories, not
only through next-token perplexity.  Memory and retrieval continuation tasks are
a natural fit: books, code, math, long-document continuation, associative
recall, and needle-style retrieval can test whether a set state preserves the
right information under compression.  This follows the motivation behind
compressive and memorizing sequence models, where useful long-context behavior
comes from storing or retrieving compact representations of past inputs rather
than from exact short-context token replacement
\citep{rae2019compressive,wu2022memorizing}.

The first implementation follow-up should not start with a broad topology
sweep.  The most useful target is the near-2 compression regime, where $L/M$ is
close to 2 and the candidate fiber still has roughly two or more sets per token.

\section{Detailed Model Definition and Structural Objects}
\label{sec:model-objects}

We now formalize the Set Attention language model studied in this work, together with the structural objects used later in the tiered theoretical analysis. The goal of this section is not merely architectural description: it fixes the finite-set, probability, and operator-theoretic objects that appear in Section~\ref{sec:theory}. Every symbol introduced here is used consistently there.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Basic Notation}
\label{sec:basic-notation}

\paragraph{Sequence, representation, and capacity parameters.}
Let:
\begin{itemize}
    \item $B \in \mathbb{N}$ denote the batch size,
    \item $L \in \mathbb{N}$ denote the token sequence length,
    \item $L_{\max}\in\mathbb N$ denote the maximum sequence length supported by the positional embedding table,
    \item $D \in \mathbb{N}$ denote the token/state embedding dimension,
    \item $K \in \mathbb N$ denote the number of set-attention blocks,
    \item $H_r \in \mathbb{N}$ denote the number of \emph{routing heads},
    \item $d_r = D/H_r$ denote the dimension per routing head,
    \item $H_a \in \mathbb{N}$ denote the number of \emph{set-attention heads},
    \item $d_a = D/H_a$ denote the dimension per set-attention head,
    \item $d_{\mathrm{ff}} \in \mathbb{N}$ denote the hidden width of the set-level feedforward network,
    \item $V_{\mathrm{vocab}} \in \mathbb{N}$ denote the vocabulary size.
\end{itemize}

\begin{remark}[Router heads vs. set-attention heads]
\label{rem:head-notation}
The routing mechanism and the set-attention stack are distinct architectural modules. Accordingly, we use different symbols for their head counts: $H_r$ for routing heads, and $H_a$ for set-attention heads. This distinction is necessary in Section~\ref{sec:theory}, where routing-head capacity and set-attention stability play different theoretical roles.
\end{remark}

\paragraph{Batch-level vs. single-sample notation.}
Unless stated otherwise, bold uppercase symbols such as $\mathbf{X}^{(0)}$,
$\mathbf{S}^{(0)}$, and $\mathbf{Z}$ denote batched tensors. When the batch
index is suppressed for a fixed sample, we reuse the same base symbol without
boldface, for example $X^{(0)}\in\mathbb R^{L\times D}$ and
$S^{(0)}\in\mathbb R^{M\times D}$. This convention is used throughout
Sections~\ref{sec:model-objects} and~\ref{sec:theory}.

\paragraph{Finite-index and probability notation.}
We write
\[
[L]:=\{1,\dots,L\}
\]
for the token-position index set. For any finite set $A$, let
\[
\Delta(A)
:=
\left\{
p:A\to[0,1]:
\sum_{a\in A} p(a)=1
\right\}
\]
denote the probability simplex on $A$. We use $\delta_a$ for the Dirac mass
concentrated at $a\in A$.
For a linear map $A$, its operator norm is
\[
\|A\|_{\mathrm{op}}:=\sup_{\|v\|_2=1}\|Av\|_2.
\]
We write $\mathbf I_D$ for the $D\times D$ identity matrix.

\paragraph{Bank construction parameters.}
Let:
\begin{itemize}
    \item $w \in \mathbb{N}$ denote the window size (number of tokens per set),
    \item $s \in \mathbb{N}$ denote the stride (spacing between consecutive set starts).
\end{itemize}
We assume throughout that
\begin{equation}
\label{eq:ws-order}
1 \le s \le w \le L.
\end{equation}

\paragraph{Pooling parameters.}
Let:
\begin{itemize}
    \item $\tau_{\mathrm{pool}} > 0$ denote the pooling temperature,
    \item $q \in (0,1)$ denote the trimming quantile,
    \item $\alpha > 0$ denote the trimming sharpness parameter.
\end{itemize}

\paragraph{Routing parameters.}
Let:
\begin{itemize}
    \item $\tau_r > 0$ denote the routing temperature,
    \item $\tau_{\min} > 0$ denote the enforced minimum routing temperature,
    \item $k \in \mathbb{N} \cup \{\infty\}$ denote the optional top-$k$ routing restriction.
\end{itemize}
The implementation clamps the routing temperature below by $\tau_{\min}$; mathematically, this means that all realized routing distributions are evaluated at an effective temperature satisfying
\begin{equation}
\label{eq:tau-clamp}
\tau_r^{\mathrm{eff}} \ge \tau_{\min}.
\end{equation}
In our current experiments, the routing configurations used for the main paper satisfy $H_r>1$, use a fixed finite routing top-$k$ configuration, and pooling is not head-aware. The routing top-$k$ value was not swept as an experimental control.

\paragraph{Embedding matrices.}
The token embedding matrix is
\begin{equation}
\label{eq:token-embedding}
\mathbf{E} \in \mathbb{R}^{V_{\mathrm{vocab}} \times D}
\end{equation}
and the positional embedding matrix is
\begin{equation}
\label{eq:pos-embedding}
\mathbf{P} \in \mathbb{R}^{L_{\max} \times D},
\end{equation}
where positional embeddings are learned absolute embeddings.

\paragraph{Input token sequence.}
An input token sequence is
\begin{equation}
\label{eq:input-sequence}
\mathbf{x}=(x_1,\dots,x_L)\in\{1,\dots,V_{\mathrm{vocab}}\}^L.
\end{equation}

\paragraph{Initial token states.}
For a fixed sample, the embedded token representation is
\begin{equation}
\label{eq:sample-token-state}
h_t^{(0)}=e(x_t)+p_t,
\qquad t\in[L],
\end{equation}
where $e(\cdot)$ denotes the learned token embedding and $p_t$ the learned positional embedding. Batched token representations collect these states as
\begin{equation}
\label{eq:token-states}
\mathbf{X}^{(0)}\in\mathbb{R}^{B\times L\times D},
\end{equation}
with $\mathbf X^{(0)}_{b,t,:}=h_{b,t}^{(0)}$.

\paragraph{Loss and perplexity.}
The training objective is the standard autoregressive cross-entropy loss. For a batch, let
\begin{equation}
\label{eq:loss}
\mathcal{L}\in\mathbb{R}
\end{equation}
denote the batch-averaged loss, and define validation perplexity by
\begin{equation}
\label{eq:perplexity}
\operatorname{PPL}=\exp(\mathcal{L}_{\mathrm{val}}).
\end{equation}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Bank Topology as a Hypergraph Incidence Structure}
\label{sec:bank-topology}

The set bank is a deterministic family of overlapping local subsets of token positions. This family is the primary finite-set object underlying the model. For the autoregressive paper mode, we use the strict-past construction: partial trailing windows are dropped, and token-to-set candidates are determined by set endpoints rather than by membership.

\paragraph{Number of sets.}
Given $L$, $w$, and $s$, the number of sets is
\begin{equation}
\label{eq:num-sets}
M=\left\lfloor\frac{L-w}{s}\right\rfloor+1.
\end{equation}

\paragraph{Set family.}
For each set index $m\in\{1,\dots,M\}$, define its start position
\begin{equation}
\label{eq:set-start}
a_m=1+(m-1)s
\end{equation}
and endpoint
\begin{equation}
\label{eq:set-endpoint}
e_m=a_m+w-1.
\end{equation}
The corresponding active token subset is
\begin{equation}
\label{eq:set-definition}
S_m=\{\,t\in[L]: a_m\le t\le e_m\,\}\subseteq[L].
\end{equation}
Thus the bank is the finite set family
\begin{equation}
\label{eq:set-family}
\mathcal{S}=\{S_1,\dots,S_M\}\subseteq 2^{[L]}.
\end{equation}

\paragraph{Trailing tokens and early positions.}
Dropping partial trailing windows means that every active set has cardinality $w$. For arbitrary $(L,w,s)$, membership in the active set family need not cover a final suffix if the last endpoint is less than $L$. Conversely, under strict-past endpoint routing, early token positions can have no available set endpoint. In that case the routed context is zero and the direct token residual carries the position.

\begin{definition}[Bank topology]
\label{def:bank-topology}
The \emph{bank topology} induced by $(L,w,s)$ is the finite hypergraph
\begin{equation}
\label{eq:bank-topology}
\mathcal{H}_{L,w,s}=([L],\mathcal S),
\qquad
[L]=\{1,\dots,L\},
\end{equation}
whose vertex set is the token-position index set and whose hyperedges are the sets in $\mathcal S$.

Equivalently, this hypergraph is represented by its incidence matrix
\begin{equation}
\label{eq:incidence-matrix}
\mathbf A\in\{0,1\}^{L\times M},
\end{equation}
with entries
\begin{equation}
\label{eq:incidence-entry}
A_{t,m}=\mathbbm{1}_{S_m}(t)=
\begin{cases}
1,& t\in S_m,\\
0,& t\notin S_m.
\end{cases}
\end{equation}
\end{definition}

\begin{remark}[Meaning of ``topology'']
\label{rem:topology-meaning}
In this paper, ``topology'' does not refer to a topological space in the sense of open sets. It refers instead to the finite bank structure $\mathcal H_{L,w,s}$ together with the active candidate rule. In strict-past mode, routing support is determined by endpoints; in the named noncausal mode, it is determined by membership. This structure determines routing support, candidate multiplicity, and the topology-induced feasible region analyzed in Section~\ref{sec:theory}.
\end{remark}

\begin{definition}[Candidate family and candidate count]
\label{def:candidate-family}
For each token position $t\in [L]$, define its strict-past \emph{candidate family}
\begin{equation}
\label{eq:candidate-family}
\mathcal C_t=\{m\in\{1,\dots,M\}: t-w<e_m\le t\},
\end{equation}
and its \emph{candidate count}
\begin{equation}
\label{eq:candidate-count}
C_t=|\mathcal C_t|.
\end{equation}
The mean candidate count is
\begin{equation}
\label{eq:mean-candidate-count}
\bar C=\frac{1}{L}\sum_{t=1}^L C_t.
\end{equation}
\end{definition}

The legacy noncausal mode uses the membership candidate family
\begin{equation}
\label{eq:noncausal-candidate-family}
\mathcal C_t^{\mathrm{nc}}=\{m\in\{1,\dots,M\}:t\in S_m\}=\{m:A_{t,m}=1\}.
\end{equation}
Unless explicitly stated otherwise, the autoregressive experiments and diagnostics in this paper use the strict-past endpoint family \eqref{eq:candidate-family}.

\begin{proposition}[Empty strict-past fibers and singleton token limit]
\label{prop:legacy-empty-strict-past-fibers}
Assume the strict-past endpoint bank above with $L\ge w\ge1$ and endpoints
$e_m=w+(m-1)s$ in 1-indexed notation. Then
\[
C_t=0 \quad\Longleftrightarrow\quad t< w .
\]
Consequently, exactly $w-1$ token positions have an empty strict-past
candidate fiber, and a uniformly sampled token position satisfies
\begin{equation}
\label{eq:empty-fiber-probability}
\mathbb P(C_t=0)=\frac{w-1}{L}.
\end{equation}
In the singleton calibration limit $w=1,s=1$, we have $M=L$, $C_t=1$ for
every $t\in[L]$, and therefore $\mathbb P(C_t=0)=0$.
\end{proposition}

\begin{proof}
The earliest sealed endpoint is $e_1=w$. If $t<w$, no endpoint can satisfy
$e_m\le t$, hence $\mathcal C_t=\varnothing$. If $t\ge w$, endpoint $e_1=w$
satisfies $t-w<w\le t$, so $1\in\mathcal C_t$ and $C_t>0$. This proves the
equivalence and the count of empty positions. Dividing by $L$ gives
\eqref{eq:empty-fiber-probability}. When $w=1,s=1$, the starts are
$a_m=m$, the endpoints are $e_m=m$, and $M=L$. For each token $t$, the
candidate condition becomes $t-1<e_m\le t$, which selects exactly
$e_m=t$.
\end{proof}

\paragraph{Residual policy for calibration.}
Proposition~\ref{prop:legacy-empty-strict-past-fibers} motivates separating the
ordinary residual architecture from calibration experiments. The default
\texttt{direct} policy uses
\[
\mathbf z_t=\mathbf X^{(0)}_{t,:}+\mathbf r_t,
\]
which is the architecture used by the main causal runs. The calibrated
\texttt{empty\_only} policy uses
\[
\mathbf z_t=
\begin{cases}
\mathbf X^{(0)}_{t,:},& C_t=0,\\
\mathbf r_t,& C_t>0.
\end{cases}
\]
Thus early strict-past tokens with no sealed endpoint still have a valid
language-model state, while tokens with nonempty set support are evaluated
through the set-routed path without an extra direct token skip. In the
$w=1,s=1$ singleton limit, the empty case never occurs, so
\texttt{empty\_only} coincides with the no-final-residual routed policy.
This makes it the appropriate named mode for empirical convergence tests as
$M/L\to1$ without introducing a residual advantage that is absent from the
matched token-attention baseline.

\begin{proposition}[Interior candidate count]
\label{prop:legacy-interior-candidate-count}
For strict-past interior token positions $t$ sufficiently far from sequence boundaries and after warmup, $C_t$ is the number of stride-spaced endpoints in the interval $(t-w,t]$.
Consequently, for sequences with $L\gg w$,
\begin{equation}
\label{eq:mean-candidate-approx}
\bar C\approx\frac{w}{s}.
\end{equation}
\end{proposition}

\begin{proof}
A set endpoint contributes to the strict-past candidate family if and only if
\[
t-w<e_m\le t.
\]
Substituting $e_m=w+(m-1)s$ gives a length-$w$ interval of admissible set endpoints on a stride-$s$ grid:
\[
\frac{t-w-w}{s}< m-1\le \frac{t-w}{s}.
\]
Thus the exact count can differ by one depending on integer alignment, but is on the order of $w/s$. Averaging over tokens and noting that warmup and boundary effects are negligible when $L\gg w$ gives $\bar C\approx w/s$.
\end{proof}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Pooling Operator as Probability Aggregation on Finite Sets}
\label{sec:pooling-operator}

Each set $S_m$ is aggregated into a single embedding by constructing a probability measure on the finite set $S_m$ and taking the expectation of the token-state function under that measure.

\paragraph{Token-state function on a set.}
For each batch element (suppressed when unambiguous) and each set $S_m$, define the token-state function
\begin{equation}
\label{eq:set-token-function}
\mathbf X^{(m)}:S_m\to\mathbb R^D,
\qquad
t\mapsto \mathbf X_{t,:}.
\end{equation}

\paragraph{Uniform set mean.}
Define the set mean embedding by
\begin{equation}
\label{eq:set-mean}
\boldsymbol\mu_m=\frac{1}{|S_m|}\sum_{t\in S_m}\mathbf X_{t,:}
\in\mathbb R^D.
\end{equation}

\paragraph{Normalized squared deviations.}
For each $t\in S_m$, define
\begin{equation}
\label{eq:normalized-deviation}
\delta_{t,m}=\frac{\|\mathbf X_{t,:}-\boldsymbol\mu_m\|_2^2}{D}\in\mathbb R_{\ge 0}.
\end{equation}
These deviations define the energy-like quantities used in the Boltzmann pooling rule.

\paragraph{Quantile threshold and soft trimming gate.}
Let
\begin{equation}
\label{eq:trimming-threshold}
\theta_m=\operatorname{Quantile}_q\bigl(\{\delta_{t,m}:t\in S_m\}\bigr).
\end{equation}
During backpropagation, $\theta_m$ is treated as gradient-detached. Define the sigmoid gate
\begin{equation}
\label{eq:sigmoid}
\sigma(u)=\frac{1}{1+e^{-u}},
\end{equation}
and the soft trimming factor
\begin{equation}
\label{eq:trimming-gate}
r^{\mathrm{trim}}_{t,m}=\sigma\bigl(\alpha(\theta_m-\delta_{t,m})\bigr)\in(0,1).
\end{equation}

\paragraph{Pooling logits and probability mass function.}
Define the pooling logits by
\begin{equation}
\label{eq:pooling-logits}
\ell^{\mathrm{pool}}_{t,m}=-\frac{\delta_{t,m}}{\tau_{\mathrm{pool}}}+\log(r^{\mathrm{trim}}_{t,m}+\varepsilon_0),
\qquad
\varepsilon_0=10^{-8}.
\end{equation}
Then define the pooling weights
\begin{equation}
\label{eq:pooling-weights}
\omega_{t,m}=\frac{\exp(\ell^{\mathrm{pool}}_{t,m})}{\sum_{u\in S_m}\exp(\ell^{\mathrm{pool}}_{u,m})},
\qquad t\in S_m.
\end{equation}
These weights define a probability measure
\begin{equation}
\label{eq:pooling-pmf}
\mathbb P_m\in\Delta(S_m),
\qquad
\mathbb P_m(\{t\})=\omega_{t,m}.
\end{equation}

\begin{remark}[Strict support vs. effective support]
\label{rem:support-vs-effective-support}
Because the implemented pooling rule uses a smooth softmax and a smooth sigmoid gate, the strict support of $\mathbb P_m$ is typically all of $S_m$. For this reason, the more informative notion of concentration is not strict support but \emph{effective support}, introduced later in Section~\ref{sec:theory} through the inverse participation ratio.
\end{remark}

\paragraph{Pooled set embedding as expectation.}
The pooled embedding for set $S_m$ is the expectation of the token-state function under $\mathbb P_m$:
\begin{equation}
\label{eq:pooled-embedding}
s_m^{(0)}
=
\mathbb E_{\mathbb P_m}[\mathbf X^{(m)}]
=
\sum_{t\in S_m}\omega_{t,m}\mathbf X_{t,:}
\in\mathbb R^D.
\end{equation}

\paragraph{Set-state tensor.}
Collecting all pooled set embeddings yields the set-state tensor
\begin{equation}
\label{eq:set-states}
\mathbf S^{(0)}\in\mathbb R^{B\times M\times D},
\qquad
\mathbf S^{(0)}_{b,m,:}=s_{b,m}^{(0)}.
\end{equation}
We use $\mathbf S^{(0)}$ as the canonical notation for post-pooling, pre-set-processing states, since this aligns cleanly with the later gradient diagnostics and theoretical objects.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Set-Processing Stack}
\label{sec:set-processing}

The pooled set states are processed by a stack of $K$ set-attention blocks.

\paragraph{Set-state recursion.}
Let
\begin{equation}
\label{eq:set-state-levels}
\mathbf S^{(\ell)}\in\mathbb R^{B\times M\times D},
\qquad
\ell\in\{0,1,\dots,K\},
\end{equation}
with $\mathbf S^{(0)}$ from \eqref{eq:set-states}. Each block computes
\begin{align}
\label{eq:block-attention}
\mathbf S^{(\ell+1/2)} &= \mathbf S^{(\ell)} + \operatorname{Dropout}\Bigl(\operatorname{SetAttention}(\operatorname{LayerNorm}(\mathbf S^{(\ell)}))\Bigr),\\
\label{eq:block-ffn}
\mathbf S^{(\ell+1)} &= \mathbf S^{(\ell+1/2)} + \operatorname{Dropout}\Bigl(\operatorname{FFN}(\operatorname{LayerNorm}(\mathbf S^{(\ell+1/2)}))\Bigr).
\end{align}

\paragraph{Causal set mask.}
For autoregressive language modeling, set attention uses a causal mask
\begin{equation}
\label{eq:causal-mask}
\mathbf C\in\{0,1\}^{M\times M},
\qquad
C_{i,j}=
\begin{cases}
1,& i\ge j,\\
0,& i<j.
\end{cases}
\end{equation}
Thus set $i$ may attend only to itself and preceding sets.

\paragraph{Multi-head set attention.}
Within each block, set attention is standard multi-head self-attention with $H_a$ heads. For each attention head $h\in\{1,\dots,H_a\}$,
\begin{align}
\label{eq:qkv-projections}
\mathbf Q^{(h)} &= \mathbf S\mathbf W_Q^{(h)} \in \mathbb R^{M\times d_a},
&\mathbf W_Q^{(h)}\in\mathbb R^{D\times d_a},\\
\mathbf K^{(h)} &= \mathbf S\mathbf W_K^{(h)} \in \mathbb R^{M\times d_a},
&\mathbf W_K^{(h)}\in\mathbb R^{D\times d_a},\\
\mathbf V^{(h)} &= \mathbf S\mathbf W_V^{(h)} \in \mathbb R^{M\times d_a},
&\mathbf W_V^{(h)}\in\mathbb R^{D\times d_a}.
\end{align}
The implemented score matrix is
\begin{equation}
\label{eq:attention-scores}
\widetilde{\mathbf A}^{(h)} \in \mathbb R^{M\times M}
=
\frac{\mathbf Q^{(h)}(\mathbf K^{(h)})^\top}{\sqrt{d_a}}
\;+\;\mathbf G
\;+\;\mathbf B^{(h)}
\;+\;(\mathbf 1_{M\times M}-\mathbf C)(-\infty),
\end{equation}
where $\mathbf G\in\mathbb R^{M\times M}$ denotes the geometry bias, $\mathbf
B^{(h)}\in\mathbb R^{M\times M}$ denotes the per-head content bias, and
$\mathbf 1_{M\times M}$ is the all-ones matrix. The corresponding attention
output is
\begin{equation}
\label{eq:attention-output}
\mathbf O^{(h)}=\operatorname{softmax}(\widetilde{\mathbf A}^{(h)})\mathbf V^{(h)}
\in \mathbb R^{M\times d_a}.
\end{equation}
Concatenation and output projection yield
\begin{equation}
\label{eq:multihead-concat}
\operatorname{SetAttention}(\mathbf S)
=
[\mathbf O^{(1)};\dots;\mathbf O^{(H_a)}]\mathbf W_O,
\qquad
\mathbf W_O\in\mathbb R^{D\times D}.
\end{equation}

\paragraph{Functional set-attention families.}
The implementation supports three functional set-processing families used in the paper bundle. The dense-exact family uses full set-to-set attention,
\begin{equation}
\label{eq:dense-set-attention-family}
\operatorname{Attn}_{\mathrm{dense}}(Q,K,V)=\operatorname{softmax}(A)V,
\end{equation}
with $A$ given by \eqref{eq:attention-scores}. The linear family used in the experiments is the landmark backend: it routes set interactions through a smaller landmark subset $\Lambda\subseteq\{1,\dots,M\}$, giving a compressed surrogate of the form
\begin{equation}
\label{eq:landmark-set-attention-family}
\operatorname{Attn}_{\mathrm{landmark}}(Q,K,V)
=
\operatorname{softmax}(A_{M\Lambda})\,
\operatorname{softmax}(A_{\Lambda M})V.
\end{equation}
The sparse family used in the experiments is local-band attention: each set attends only within a fixed neighborhood in bank-index space,
\begin{equation}
\label{eq:local-band-set-attention-family}
A_{ij}=-\infty\quad\text{whenever}\quad |i-j|>r,
\end{equation}
up to optional global indices and the causal/set masks. We do not include the Nystr\"om backend in the main paper, since it was not part of the functional family emphasized by the reported experiments.

\paragraph{Set-level feedforward network.}
The block feedforward network is
\begin{equation}
\label{eq:ffn}
\operatorname{FFN}(\mathbf s)=\mathbf W_2\,\operatorname{GELU}(\mathbf W_1\mathbf s),
\end{equation}
with
\begin{equation}
\mathbf W_1\in\mathbb R^{d_{\mathrm{ff}}\times D},
\qquad
\mathbf W_2\in\mathbb R^{D\times d_{\mathrm{ff}}}.
\end{equation}

\paragraph{Processed set states and operator notation.}
After $K$ blocks, the processed set states are
\begin{equation}
\label{eq:final-set-states}
\widetilde{\mathbf S}=\mathbf S^{(K)}\in\mathbb R^{B\times M\times D}.
\end{equation}
We write the full set-processing stack as the operator
\begin{equation}
\label{eq:set-stack-operator}
\Phi_{\mathrm{set}}:\mathbb R^{M\times D}\to\mathbb R^{M\times D},
\qquad
\widetilde{\mathbf S}=\Phi_{\mathrm{set}}(\mathbf S^{(0)}).
\end{equation}

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Multi-Head Routing Operator}
\label{sec:routing-operator}

The routing operator maps processed set states back to token-level representations. This module is multi-head in all main set-only experiments used for the paper.

\paragraph{Head splitting of set states.}
For each processed set state $\widetilde{\mathbf S}_m\in\mathbb R^D$, split its coordinates into $H_r$ routing-head subvectors:
\begin{equation}
\label{eq:head-split}
\widetilde{\mathbf S}_m=\bigl[\widetilde{\mathbf S}_m^{(1)};\dots;\widetilde{\mathbf S}_m^{(H_r)}\bigr],
\qquad
\widetilde{\mathbf S}_m^{(u)}\in\mathbb R^{d_r}.
\end{equation}
%Equivalently,
%\begin{equation}
%\label{eq:head-split-concat}
%\widetilde{\mathbf S}=\operatorname{Concat}(\widetilde{\mathbf S}^{(1)},\dots,\widetilde{\mathbf S}^{(H_r)}),
%\qquad
%\widetilde{\mathbf S}^{(u)}\in\mathbb R^{M\times d_r}.
%\end{equation}

\paragraph{Per-head routing scores.}
For each token position $t$ and routing head $u\in\{1,\dots,H_r\}$, the learned router computes headwise token-query / set-descriptor compatibility scores. Let $d_m$ denote the descriptor used by the router for set $m$. In the hashed-count experimental path used in the paper, the router receives the pre-set-attention pooled state as this descriptor, so $d_m=s_m^{(0)}$; the hashed-count features affect set attention through content bias. The router computes
\begin{equation}
\label{eq:routing-query-key}
q_t^{(u)}=W_{Q,r}^{(u)}h_t^{(0)},
\qquad
k_m^{(u)}=W_{K,r}^{(u)}d_m,
\end{equation}
and raw scores
\begin{equation}
\label{eq:routing-scores}
g^{(u)}_{t,m}
=
\frac{\langle q_t^{(u)},k_m^{(u)}\rangle}{\sqrt{d_\phi}},
\qquad m\in\{1,\dots,M\}.
\end{equation}
Here $d_\phi$ is the router projection dimension; when a single-head router is used, the same expression reduces to the corresponding full-width query--descriptor dot product.

\paragraph{Candidate masking and optional top-$k$ restriction.}
The topology restricts routing to candidate sets in $\mathcal C_t$. The reported experiments keep a fixed finite router top-$k$ setting rather than sweeping it; in the dense-exact operating points emphasized below, this cutoff is effectively inactive whenever $C_t$ is already smaller than the configured value. Define the masked logits
\begin{equation}
\label{eq:masked-logits}
\widetilde g^{(u)}_{t,m}=
\begin{cases}
g^{(u)}_{t,m},& m\in\mathcal C_t \text{ and } m \text{ survives top-}k,\\
-\infty,& \text{otherwise}.
\end{cases}
\end{equation}

\paragraph{Per-head routing probability measures.}
For each token position $t$ and head $u$, define the routing probability measure
\begin{equation}
\label{eq:routing-probability-measure}
\mathbb Q_t^{(u)}\in\Delta(\mathcal C_t)
\end{equation}
when $C_t>0$, with mass function
\begin{equation}
\label{eq:routing-probabilities}
\pi_{t,m}^{(u)}=\mathbb Q_t^{(u)}(\{m\})
=
\frac{\exp(\widetilde g^{(u)}_{t,m}/\tau_r^{\mathrm{eff}})}{\sum_{j=1}^M \exp(\widetilde g^{(u)}_{t,j}/\tau_r^{\mathrm{eff}})}.
\end{equation}
Its support is
\begin{equation}
\label{eq:routing-support}
\operatorname{supp}(\mathbb Q_t^{(u)})
=
\{m\in\mathcal C_t: \pi_{t,m}^{(u)}>0\}
\subseteq \mathcal C_t.
\end{equation}
Each headwise routing distribution satisfies
\begin{equation}
\label{eq:routing-prob-sum}
\sum_{m=1}^M \pi_{t,m}^{(u)}=1.
\end{equation}
When $C_t=0$ in strict-past mode, no softmax is formed for that token and the routed context below is set to zero.

\paragraph{Per-head routed context.}
For each head $u$, define the routed head-subvector as the expectation of the head-split set-state function under $\mathbb Q_t^{(u)}$:
\begin{equation}
\label{eq:per-head-routed}
\mathbf r_t^{(u)}
=
\mathbb E_{\mathbb Q_t^{(u)}}[\widetilde{\mathbf S}^{(u)}]
=
\sum_{m=1}^M \pi_{t,m}^{(u)}\widetilde{\mathbf S}^{(u)}_m
\in\mathbb R^{d_r}.
\end{equation}

\paragraph{Routed context and output residual policy.}
The routed context is the concatenation of headwise routed subvectors:
\begin{equation}
\label{eq:routed-token}
\mathbf r_t
=
\operatorname{Concat}(\mathbf r_t^{(1)},\dots,\mathbf r_t^{(H_r)})
\in\mathbb R^D.
\end{equation}
If $C_t=0$, define $\mathbf r_t=\mathbf 0$. The default final token representation is the direct residual
\begin{equation}
\label{eq:direct-residual-appendix}
\mathbf z_t=\mathbf X^{(0)}_{t,:}+\mathbf r_t.
\end{equation}
For explicitly configured calibration runs, the \texttt{empty\_only} policy
instead uses $\mathbf z_t=\mathbf X^{(0)}_{t,:}$ when $C_t=0$ and
$\mathbf z_t=\mathbf r_t$ when $C_t>0$; the \texttt{none} policy uses
$\mathbf z_t=\mathbf r_t$ throughout strict-past mode.
Collecting all token positions yields the final token-state tensor
\begin{equation}
\label{eq:routed-tokens}
\mathbf Z\in\mathbb R^{B\times L\times D}.
\end{equation}

\paragraph{Head-aggregated routing distribution.}
For analysis and diagnostics, define the head-aggregated routing distribution by
\begin{equation}
\label{eq:aggregated-routing}
\bar\pi_{t,m}=\frac{1}{H_r}\sum_{u=1}^{H_r}\pi_{t,m}^{(u)}.
\end{equation}
This defines a probability measure
\begin{equation}
\label{eq:aggregated-routing-measure}
\bar{\mathbb Q}_t\in\Delta(\mathcal C_t),
\qquad
\bar{\mathbb Q}_t(\{m\})=\bar\pi_{t,m}.
\end{equation}

\paragraph{Operator notation.}
We write the multi-head routing operator as
\begin{equation}
\label{eq:routing-operator}
\mathcal R_{H_r,\tau_r,\mathcal H,k}:\mathbb R^{M\times D}\to\mathbb R^{L\times D},
\qquad
\mathbf R=\mathcal R_{H_r,\tau_r,\mathcal H,k}(\widetilde{\mathbf S}),
\end{equation}
where $\mathcal H=\mathcal H_{L,w,s}$ is the bank topology, and $\mathbf Z$ is formed from $\mathbf X^{(0)}$ and $\mathbf R$ by the configured output residual policy before being passed to the language-model head.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Language Model Head and Loss}
\label{sec:lm-head}

The final token representations are mapped to vocabulary logits by a linear readout:
\begin{equation}
\label{eq:output-logits}
\mathbf Y=\mathbf Z\mathbf W_{\mathrm{lm}}^\top+\mathbf b_{\mathrm{lm}}
\in\mathbb R^{B\times L\times V_{\mathrm{vocab}}},
\end{equation}
where
\begin{equation}
\mathbf W_{\mathrm{lm}}\in\mathbb R^{V_{\mathrm{vocab}}\times D},
\qquad
\mathbf b_{\mathrm{lm}}\in\mathbb R^{V_{\mathrm{vocab}}}.
\end{equation}
For a fixed sample, write $y_t\in\mathbb R^{V_{\mathrm{vocab}}}$ for the vocabulary-logit vector at token position $t$. The autoregressive cross-entropy loss functional is
\begin{equation}
\label{eq:cross-entropy}
\mathcal J
=
-\frac{1}{L}\sum_{t=1}^{L}
\log p_{\mathrm{model}}(x^{\mathrm{target}}_t\mid y_t).
\end{equation}
Here the data loader supplies pre-shifted input and target chunks: the model consumes the input chunk and predicts the aligned next-token target chunk at every label position. The empirical batch loss $\mathcal L$ is the average of $\mathcal J$ over all batch and label positions.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Complete Architecture Summary}
\label{sec:architecture-summary}

The full Set Attention language model is the composition:
\begin{equation}
\label{eq:full-pipeline}
\mathbf x
\xrightarrow{\mathrm{Embed}}
\mathbf X^{(0)}
\xrightarrow{\mathcal P}
\mathbf S^{(0)}
\xrightarrow{\Phi_{\mathrm{set}}}
\widetilde{\mathbf S}
\xrightarrow{\mathcal R}
\mathbf R
\xrightarrow{+\mathbf X^{(0)}}
\mathbf Z
\xrightarrow{\mathrm{LM\ Head}}
\mathbf Y,
\end{equation}
where:
\begin{itemize}
    \item $\mathcal P=\mathcal P_{w,s,q,\alpha,\tau_{\mathrm{pool}}}$ is the pooling operator on bank sets,
    \item $\Phi_{\mathrm{set}}$ is the set-processing stack,
    \item $\mathcal R=\mathcal R_{H_r,\tau_r,\mathcal H,k}$ is the multi-head routing operator.
\end{itemize}

\paragraph{Architectural parity fact.}
There is no post-routing token-level MLP in the main proposal. The only feedforward network active in the core architecture is the set-level FFN inside each set-attention block. This fact is important in Section~\ref{sec:theory}, where the theoretical analysis focuses on the set-attention and routing mechanism itself rather than on an added post-routing token nonlinearity.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\subsection{Observable Routing Diagnostics}
\label{sec:routing-diagnostics}

This subsection defines the routing diagnostics used later in Section~\ref{sec:theory} and in the experiments.

\paragraph{Per-head routing entropy.}
For each token $t$ and routing head $u$, define the Shannon entropy
\begin{equation}
\label{eq:per-head-entropy-single}
H(\mathbb Q_t^{(u)})
=
-\sum_{m=1}^M \pi_{t,m}^{(u)}\log \pi_{t,m}^{(u)}.
\end{equation}
The mean per-head routing entropy is
\begin{equation}
\label{eq:per-head-entropy-mean}
H_{\mathrm{head}}
=
\frac{1}{LH_r}
\sum_{t=1}^L\sum_{u=1}^{H_r}
H(\mathbb Q_t^{(u)}).
\end{equation}

\paragraph{Aggregated routing entropy.}
For each token position $t$, define the entropy of the aggregated routing distribution
\begin{equation}
\label{eq:aggregated-entropy-single}
H(\bar{\mathbb Q}_t)
=
-\sum_{m=1}^M \bar\pi_{t,m}\log \bar\pi_{t,m}.
\end{equation}
Its mean over tokens is
\begin{equation}
\label{eq:aggregated-entropy}
H_{\mathrm{agg}}
=
\frac{1}{L}\sum_{t=1}^L H(\bar{\mathbb Q}_t).
\end{equation}

\paragraph{Normalized aggregated entropy.}
To align with the sharp structural bounds in Section~\ref{sec:theory}, define the per-token normalized aggregated entropy by
\begin{equation}
\label{eq:normalized-agg-entropy-token}
\overline H_{\mathrm{agg}}(t)
=
\frac{H(\bar{\mathbb Q}_t)}{\log C_t},
\qquad C_t\ge 2,
\end{equation}
and the mean normalized aggregated entropy by
\begin{equation}
\label{eq:normalized-agg-entropy}
\overline H_{\mathrm{agg}}
=
\frac{1}{|\{t:C_t\ge 2\}|}
\sum_{t:C_t\ge 2}
\frac{H(\bar{\mathbb Q}_t)}{\log C_t}.
\end{equation}
This normalization places the quantity in $[0,1]$ and matches the candidate-family-based entropy bounds used later.

\paragraph{Router top-1 concentration.}
The reported router top-1 diagnostic is probability concentration, not modal head agreement. For each token with nonempty candidate set, define
\begin{equation}
\label{eq:router-top1-concentration-token}
\kappa_t=\frac{1}{H_r}\sum_{u=1}^{H_r}\max_{m\in\mathcal C_t}\pi_{t,m}^{(u)}.
\end{equation}
The mean router top-1 concentration is the average of $\kappa_t$ over tokens with $C_t>0$. It lies in $[1/C_t,1]$ per token when all candidates survive masking and equals $1$ for deterministic routing.

\paragraph{Head agreement.}
For each token $t$, define the top-1 agreement score
\begin{equation}
\label{eq:head-agreement-token}
a_t
=
\frac{1}{H_r}
\max_{m\in\mathcal{C}_t}
\sum_{u=1}^{H_r}
\mathbbm{1}_{\left[\arg\max_{j\in\mathcal{C}_t} \pi_{t,j}^{(u)}=m\right]}
\in\left[\frac{1}{H_r},1\right].
\end{equation}
This score is modal top-1 agreement across routing heads; it is not a measure of full distributional agreement.
The mean head agreement is
\begin{equation}
\label{eq:head-agreement}
\mathcal A
=
\frac{1}{L}\sum_{t=1}^L a_t.
\end{equation}

\paragraph{Head diversity via Jensen--Shannon deviation from the mean.}
For probability laws $p,q\in\Delta(A)$ on a common finite support $A$, define
\[
\operatorname{KL}(p\,\|\,q)
:=
\sum_{a\in A} p(a)\log\frac{p(a)}{q(a)}.
\]
For each token $t$ and head $u$, let
\[
m_t^{(u)}=\tfrac12\left(\mathbb Q_t^{(u)}+\bar{\mathbb Q}_t\right).
\]
Define the Jensen--Shannon divergence from the aggregated routing distribution by
\begin{equation}
\label{eq:js-divergence}
\operatorname{JS}(\mathbb Q_t^{(u)}\,\|\,\bar{\mathbb Q}_t)
=
\frac{1}{2}\operatorname{KL}(\mathbb Q_t^{(u)}\,\|\,m_t^{(u)})
+
\frac{1}{2}\operatorname{KL}(\bar{\mathbb Q}_t\,\|\,m_t^{(u)}).
\end{equation}
The mean JS-to-mean diversity is
\begin{equation}
\label{eq:js-diversity}
\mathcal D_{\mathrm{JS}}
=
\frac{1}{LH_r}
\sum_{t=1}^L\sum_{u=1}^{H_r}
\operatorname{JS}(\mathbb Q_t^{(u)}\,\|\,\bar{\mathbb Q}_t).
\end{equation}

\subsection{Gradient Flow Diagnostics}
\label{sec:gradient-flow-diagnostics}

This subsection fixes the gradient-flow observables used later in the mechanistic analysis.

\paragraph{Intermediate states for gradient diagnostics.}
Let:
\begin{itemize}
    \item $\mathbf h\in\mathbb R^{L\times D}$ denote token states immediately before pooling,
    \item $\mathbf z_0\in\mathbb R^{M\times D}$ denote set states immediately after pooling,
    \item $\mathbf z_K\in\mathbb R^{M\times D}$ denote set states immediately after the set-processing stack.
\end{itemize}
These correspond respectively to the tensor stages $\mathbf X^{(0)}$, $\mathbf S^{(0)}$, and $\widetilde{\mathbf S}$ for a fixed batch element, with notation simplified for the gradient analysis.

\paragraph{Pooling gradient-flow ratio.}
Define
\begin{equation}
\label{eq:rho-p}
\rho_p
=
\frac{\|\nabla_{\mathbf z_0}\mathcal L\|_2}{\|\nabla_{\mathbf h}\mathcal L\|_2+\varepsilon_g},
\qquad
\varepsilon_g=10^{-8}.
\end{equation}

\paragraph{Set-processing gradient-flow ratio.}
Define
\begin{equation}
\label{eq:rho-a}
\rho_a
=
\frac{\|\nabla_{\mathbf z_K}\mathcal L\|_2}{\|\nabla_{\mathbf z_0}\mathcal L\|_2+\varepsilon_g}.
\end{equation}

\paragraph{Combined gradient-flow ratio.}
Define
\begin{equation}
\label{eq:rho-pa}
\rho_{pa}
=
\frac{\|\nabla_{\mathbf z_K}\mathcal L\|_2}{\|\nabla_{\mathbf h}\mathcal L\|_2+\varepsilon_g}.
\end{equation}

\paragraph{Exact stabilizer-corrected multiplicative relation.}
These quantities satisfy the exact identity
\begin{equation}
\label{eq:rho-composition-corrected}
\rho_p\rho_a
=
\rho_{pa}
\frac{\|\nabla_{\mathbf z_0}\mathcal L\|_2}{\|\nabla_{\mathbf z_0}\mathcal L\|_2+\varepsilon_g}.
\end{equation}
Hence the idealized multiplicative relation $\rho_{pa}=\rho_p\rho_a$ is recovered in the limit $\varepsilon_g\to 0$.

\paragraph{Interpretation.}
These ratios are used as local diagnostics of gradient transport through the architectural stages:
\begin{itemize}
    \item $\rho_p\ll 1$: pooling-related gradient bottleneck,
    \item $\rho_p\gg 1$: pooling-related gradient amplification,
    \item $\rho_a\ll 1$: set-stack-related gradient decay,
    \item $\rho_a\gg 1$: set-stack-related gradient amplification.
\end{itemize}

\section{Current Multiresolution Theory and Proofs}
\label{sec:theory}

This appendix is the canonical theory for the current set-dictionary branch.  It supersedes the older single-resolution \texttt{direct}/\texttt{empty\_only} proof sketch for the claims cited from Section~\ref{sec:main-theory}.  The executed branch uses exact dense set attention, strict-past banks, endpoint-window candidate gather, fine groups $(w,s,H)=(2,1,6)$, coarse groups $(4,2,2)$, $D=384$, $d_{\rm ff}=1536$, $K=6$, $H=8$, token MLP disabled, trained anchor disabled, hashed-count features, and \texttt{anchor\_span} readout.

\subsection{Notation and Dimensions}
\label{sec:mrp6-notation}

Let $x_0,\ldots,x_{L-1}$ be a token sequence.  A resolution group $g\in\mathcal G$ has window $w_g$, stride $s_g$, routing-head set $\mathcal U_g$, head count $H_g=|\mathcal U_g|$, and stream width $D_g=D_{\rm set}H_g/H$, with $\sum_gH_g=H$.  The implementation enforces divisibility so each head slice has width $D_g/H_g$.  In the active rows $D_{\rm set}=D=384$, so concatenated routed streams already have model width; $W_o$ is kept explicit for code paths with $D_{\rm set}\ne D$.  The router uses a positive temperature floor $\tau_{\min}>0$.

The thin anchor is
\begin{equation}
h_t^{(0)}=e(x_t)+p_t.
\end{equation}
For group $g$, define
\begin{equation}
M_g(L)=\begin{cases}
0,&L<w_g,\\
\lfloor(L-w_g)/s_g\rfloor+1,&L\ge w_g,
\end{cases}
\qquad
a_m^g=ms_g,
\qquad
e_m^g=a_m^g+w_g-1,
\end{equation}
for $m=0,\ldots,M_g-1$.  The group set is $S_m^g=\{a_m^g,\ldots,e_m^g\}$ and the endpoint-window fiber is
\begin{equation}
\mathcal C_t^g=\{m:t-w_g<e_m^g\le t\},\qquad c_t^g=|\mathcal C_t^g|.
\end{equation}

\subsection{Bank Construction}
\label{sec:mrp6-bank}

\begin{lemma}[Group-local empty and interior fibers]
\label{prop:empty-strict-past-fibers}
For group $g$, $\mathcal C_t^g$ is empty exactly when there is no integer $m$ such that
\begin{equation}
0\le m\le M_g-1,
\qquad
\left\lceil\frac{t-2w_g+2}{s_g}\right\rceil\le m\le \left\lfloor\frac{t-w_g+1}{s_g}\right\rfloor.
\end{equation}
Equivalently, with
\begin{equation}
\ell_t^g=\max\!\left(0,\left\lceil\frac{t-2w_g+2}{s_g}\right\rceil\right),\qquad
\nu_t^g=\min\!\left(M_g-1,\left\lfloor\frac{t-w_g+1}{s_g}\right\rfloor\right),
\end{equation}
we have $c_t^g=\max(0,\nu_t^g-\ell_t^g+1)$.  If $s_g\le w_g$ and boundary truncations are inactive, $c_t^g$ is the number of stride-grid endpoints in $(t-w_g,t]$, hence is either $\lfloor w_g/s_g\rfloor$ or $\lceil w_g/s_g\rceil$.  For the active fine and coarse groups the interior count is $2$.
\end{lemma}

\begin{proof}
Substituting $e_m^g=ms_g+w_g-1$ into $t-w_g<e_m^g\le t$ gives
$t-2w_g+1<ms_g\le t-w_g+1$, which is the displayed integer interval after applying ceiling and floor and intersecting with valid bank indices.  The count of integers in a nonempty closed integer interval is upper endpoint minus lower endpoint plus one.  The endpoint-local statement follows because every candidate endpoint lies in the integer interval $(t-w_g,t]$, and a length-$w_g$ interval intersects an $s_g$-spaced grid in either floor or ceiling many points.  For $(2,1)$ and $(4,2)$ this value is exactly $2$ away from boundaries.  This proof uses the moving recent endpoint grid and does not keep the first endpoint in all later fibers.
\end{proof}

\begin{proposition}[Interior candidate count]
\label{prop:interior-candidate-count}
Under the assumptions of Lemma~\ref{prop:empty-strict-past-fibers}, interior token positions have group-local candidate count
\begin{equation}
c_t^g=\left\lfloor\frac{t-w_g+1}{s_g}\right\rfloor-
\left\lceil\frac{t-2w_g+2}{s_g}\right\rceil+1.
\end{equation}
The count is a structural property of the group bank and does not by itself imply a quality ordering.
\end{proposition}

\begin{proof}
This is Lemma~\ref{prop:empty-strict-past-fibers} with the boundary clamps removed.  The final sentence is a scope statement: quality depends on learned atoms, routing, optimization, and data, none of which appears in the counting formula.
\end{proof}

\subsection{Group-Local Pooling, Features, Set Stacks, and Routing}
\label{sec:mrp6-group-local}

Each group pools the thin anchors inside its own bank:
\begin{equation}
z_m^{0,g}=\mathcal P_g(\{h_j^{(0)}:j\in S_m^g\}).
\end{equation}
The active pooling rule is soft-trimmed Boltzmann pooling.  Its pure Boltzmann factor has weights proportional to $\exp(-\delta_{j,m}/\tau_{\rm pool})$; the implementation multiplies that factor by a differentiable trimming gate and renormalizes.  Hashed-count and geometry descriptors are group-local deterministic functions of tokens and positions inside the same bank.  A causal $K$-block set stack $\Phi_g$ produces atoms $z_m^{K,g}$, with the mask $e_j^g\le e_m^g$ for source atom $j$ consumed by atom $m$.

For head $u\in\mathcal U_g$, the router scores only candidates in $\mathcal C_t^g$, applies optional top-$k$ masking, and softmaxes at effective temperature at least $\tau_{\min}$.  If the fiber is empty, the implementation emits the zero route.  Otherwise
\begin{equation}
\pi_{t,m}^{u,g}\ge0,
\qquad
\sum_{m\in\mathcal C_t^g}\pi_{t,m}^{u,g}=1,
\qquad
r_t^{u,g}=\sum_{m\in\mathcal C_t^g}\pi_{t,m}^{u,g}\,\operatorname{slice}_{u,g}(z_m^{K,g}).
\end{equation}
The routed group vector is $r_t^g=\operatorname{Concat}_{u\in\mathcal U_g}r_t^{u,g}$.

\subsection{Concatenated \texttt{anchor\_span} Readout}
\label{sec:mrp6-anchor-span}

The full route and span are
\begin{equation}
r_t=\operatorname{Concat}_{g\in\mathcal G}r_t^g,
\qquad
\operatorname{span}_t=W_o r_t.
\end{equation}
The active logits are
\begin{equation}
f_t=h_t^{(0)}+\operatorname{span}_t,
\qquad
\ell_t=W_{\rm lm}f_t.
\end{equation}
There is no direct contextual token residual, no token MLP, and no trained anchor in the active branch.  Span ablation sets $r_t:=0$; the remaining readout depends on the current token and position and is not a pure unigram regime.

\subsection{Tier A Exact Results}
\label{sec:mrp6-tier-a}

\begin{theorem}[Causal closure]
\label{thm:mrp6-causal-closure}
For every group $g$, layer $k$, atom $m$, and token $t$, $z_m^{k,g}$ depends only on $x_0,\ldots,x_{e_m^g}$, and $r_t^g$, $r_t$, $\operatorname{span}_t$, and $\ell_t$ depend only on $x_0,\ldots,x_t$.  The model is next-token causal.
\end{theorem}

\begin{proof}
The pooled atom $z_m^{0,g}$ is computed from anchors in $S_m^g$, whose largest index is $e_m^g$; soft-trimmed pooling weights, hashed counts, and geometry descriptors use no later token.  Induct on set-stack depth.  At layer $k+1$, the causal set mask permits atom $m$ to consume only atoms $j$ with $e_j^g\le e_m^g$.  By the induction hypothesis, those source atoms are functions of prefixes contained in $x_{\le e_m^g}$, and layer normalization, score biases, attention, residual updates, and the set FFN are deterministic functions of those inputs.  Thus $z_m^{k+1,g}$ is endpoint-measurable.  At token $t$, routing uses only atoms with $e_m^g\le t$ plus the current anchor query $h_t^{(0)}$; empty fibers give a deterministic zero vector.  Concatenation, $W_o$, anchor addition, and $W_{\rm lm}$ preserve dependence on $x_{\le t}$.
\end{proof}

\begin{theorem}[Contextual-path factorization]
\label{thm:contextual-path-factorization}
If two histories $x,x'$ share current token and position at $t$, then
\begin{equation}
\ell_t(x)-\ell_t(x')=W_{\rm lm}W_o\bigl(r_t(x)-r_t(x')\bigr).
\end{equation}
Consequently all historical-context dependence factors through the routed span.  Softmax probabilities cannot distinguish span differences mapped by $W_{\rm lm}W_o$ to an all-classes constant logit shift.
\end{theorem}

\begin{proof}
The readout is $\ell_t(x)=W_{\rm lm}(h_t^{(0)}(x)+W_o r_t(x))$.  Equal current token and equal position imply $h_t^{(0)}(x)=h_t^{(0)}(x')$.  Subtracting cancels the anchor and leaves the displayed identity.  The observability qualification is the standard softmax invariance under adding $c\mathbf 1$ to the logits.
\end{proof}

\begin{theorem}[Per-group routing entropy and top-$k$]
\label{thm:per-head-entropy}
For nonempty $\mathcal C_t^g$ and head $u\in\mathcal U_g$,
\begin{equation}
0\le H(\pi_t^{u,g})\le \log |\operatorname{supp}(\pi_t^{u,g})|\le \log c_t^g.
\end{equation}
With top-$k$ masking, $|\operatorname{supp}(\pi_t^{u,g})|\le \min\{c_t^g,k\}$.  If $c_t^g=1$, the group-local routing law is the unique Dirac law; finite logits, learned scores, and temperature cannot change it.  For fixed finite support and fixed masked logits, entropy is nondecreasing in the routing temperature, tends to zero as temperature tends to $0^+$ when the maximum is unique, and tends to the uniform-support entropy as temperature tends to infinity.
\end{theorem}

\begin{proof}
The entropy bound is the finite-support entropy maximum principle, with equality only at the uniform law.  Top-$k$ can leave at most $k$ candidates and cannot add candidates outside $\mathcal C_t^g$.  When $c_t^g=1$, the simplex has one element, so the law is forced.  For the temperature claim, write $p_i(\tau)=\exp(a_i/\tau)/\sum_j\exp(a_j/\tau)$ on a fixed support.  Then $H(p(\tau))=\log Z(\tau)-\tau^{-1}\mathbb E_p[a]$ and differentiation gives $dH/d\tau=\operatorname{Var}_p(a)/\tau^3\ge0$.  The two limits follow from the softmax limits on a finite set.
\end{proof}

\begin{corollary}[Normalized head entropy]
\label{cor:normalized-head-entropy}
If $|\operatorname{supp}(\pi_t^{u,g})|\ge2$, then $H(\pi_t^{u,g})/\log |\operatorname{supp}(\pi_t^{u,g})|\in[0,1]$.
\end{corollary}
\begin{proof}
Divide the preceding entropy bound by the positive denominator.
\end{proof}

\begin{theorem}[Group-local aggregated entropy]
\label{thm:aggregated-vs-head-entropy}
Within a fixed group $g$, the averaged law $\bar\pi_t^g=H_g^{-1}\sum_{u\in\mathcal U_g}\pi_t^{u,g}$ satisfies
\begin{equation}
H(\bar\pi_t^g)\ge H_g^{-1}\sum_{u\in\mathcal U_g}H(\pi_t^{u,g}).
\end{equation}
The statement is not defined across groups unless the atoms are first embedded in the tagged disjoint union.
\end{theorem}
\begin{proof}
Entropy is concave on one finite simplex.  The final sentence records the domain condition: different groups have different atom spaces, so untagged averaging is ill-typed.
\end{proof}

\begin{remark}[Entropy gap interpretation]
\label{rem:entropy-gap-interpretation}
Within a group, the entropy gap measures diversity among heads over the same candidate atom labels.  It is not a cross-resolution diversity measure without explicit tags.
\end{remark}

\begin{proposition}[Support and entropy cap under top-$k$]
\label{prop:topk-support-entropy}
For each group and head, top-$k$ routing gives $|\operatorname{supp}(\pi_t^{u,g})|\le\min\{c_t^g,k\}$ and $H(\pi_t^{u,g})\le\log\min\{c_t^g,k\}$.
\end{proposition}
\begin{proof}
Immediate from the candidate mask, the top-$k$ mask, and Theorem~\ref{thm:per-head-entropy}.
\end{proof}

\begin{theorem}[Group-local degenerate topology]
\label{thm:degenerate-topology}
If $c_t^g=1$ for a group at token $t$, every head in $\mathcal U_g$ routes to the unique candidate, has zero entropy, and is independent of learned scores and temperature.  Empty fibers contribute the zero group route, not an empty-only residual branch.
\end{theorem}
\begin{proof}
The probability simplex over one candidate contains one point.  Empty-fiber behavior is the implementation convention described in Section~\ref{sec:mrp6-group-local}.
\end{proof}

\begin{corollary}[Stride equals window]
\label{cor:stride-equals-window}
If $s_g=w_g$, then every interior token has $c_t^g=1$, so Theorem~\ref{thm:degenerate-topology} applies group-locally.
\end{corollary}
\begin{proof}
Interior endpoint intervals $(t-w_g,t]$ have length $w_g$ and the endpoint grid spacing is exactly $w_g$, so exactly one endpoint lies in the interval.
\end{proof}

\begin{theorem}[Direct-sum routing capacity]
\label{thm:direct-sum-routing-capacity}
For each group, let $\Pi_t^g$ have rows indexed by $u\in\mathcal U_g$ and columns by $\mathcal C_t^g$.  Define $\widehat\Pi_t$ over $\Omega_t=\bigsqcup_g(\{g\}\times\mathcal C_t^g)$ by placing each row only in its group block.  Then
\begin{equation}
\operatorname{rank}(\widehat\Pi_t)=\sum_g\operatorname{rank}(\Pi_t^g)\le\sum_g\min\{H_g,c_t^g\}.
\end{equation}
The admissible assignment space has relative-interior dimension $\sum_g H_g(c_t^g-1)$ over nonempty nonsingleton fibers.
\end{theorem}
\begin{proof}
After permuting rows and columns by group, $\widehat\Pi_t$ is block diagonal with diagonal blocks $\Pi_t^g$.  Rank is additive across block diagonal matrices, and each block rank is bounded by its number of rows and columns.  The dimension formula is the sum of the dimensions of the product of group-head simplices.
\end{proof}

\begin{corollary}[Topology-limited routing capacity]
\label{cor:topology-limited-routing-capacity}
For active interior tokens, the registered ceilings are $2$ for b0, $4$ for b25, $4$ for b50, $4$ for b75, and $2$ for b100.  This distinguishes mixed rows from uniform endpoints but cannot select among b25, b50, and b75.
\end{corollary}
\begin{proof}
Interior fine and coarse fibers both have count $2$.  Substitute the blur head splits into $\sum_g\min\{H_g,2\}$.
\end{proof}

\begin{theorem}[Exact dense score-memory law]
\label{thm:exact-dense-score-memory}
The materialized score tensor count across batch and set-attention layers is
\begin{equation}
A_{\rm score}(L,B)=BK\sum_gH_gM_g(L)^2.
\end{equation}
For fine $(2,1)$ and coarse $(4,2)$, $M_f=L-1$, $M_c=\lfloor(L-4)/2\rfloor+1$, and for even $L$, $M_c=L/2-1$.  With coarse-head fraction $p$,
\begin{equation}
\frac{A_{\rm score}}{BKHL^2}=1-\frac{3p}{4}+O(L^{-1}).
\end{equation}
Replacing one fine head by one coarse head strictly decreases this count for registered $L\ge4$ while preserving $\Theta(L^2)$ exact-dense scaling.
\end{theorem}
\begin{proof}
The exact backend forms a full $B\times H_g\times M_g\times M_g$ score tensor in every group and every layer before applying masks.  Summing these cardinalities over groups and $K$ layers gives the count.  The formulas for $M_f$ and $M_c$ are direct substitutions into the strict-past bank formula.  Since $M_f=L-1$ and $M_c\le L/2-1<M_f$ for $L\ge4$, replacing one fine head changes the count by $BK(M_c^2-M_f^2)<0$.  The asymptotic coefficient follows from $M_g=L/s_g+O(1)$.
\end{proof}

\subsection{Tier B Conditional Results}
\label{sec:mrp6-tier-b}

\begin{theorem}[Routed approximation and span coupling]
\label{thm:mechanistic-decomposition}
For group $g$ and head $u$, suppose implemented candidates are coupled to reference atoms $a_i^{u,g}$ by $\kappa_t^g$, with
\begin{equation}
\|\operatorname{slice}_{u,g}(z_m^{K,g})-a_{\kappa_t^g(m)}^{u,g}\|\le\epsilon_g,
\quad
\|a_i^{u,g}\|\le B_g,
\quad
\operatorname{TV}(\kappa_{t\#}^g\pi_t^{u,g},\rho_t^{u,g})\le\xi_g.
\end{equation}
Then
\begin{equation}
\|r_t^{u,g}-r_{*,t}^{u,g}\|\le\epsilon_g+2B_g\xi_g
\end{equation}
and
\begin{equation}
\|\Delta\operatorname{span}_t\|
\le
\|W_o\|_{\rm op}\left[\sum_gH_g(\epsilon_g+2B_g\xi_g)^2\right]^{1/2}.
\end{equation}
\end{theorem}
\begin{proof}
Let $\mu=\kappa_{t\#}^g\pi_t^{u,g}$.  Insert and subtract the coupled implemented route:
\begin{equation}
r_t^{u,g}-r_{*,t}^{u,g}=\sum_i\mu_i(z_i-a_i)+\sum_i(\mu_i-\rho_i)a_i.
\end{equation}
The first term has norm at most $\epsilon_g$ and the second at most $B_g\|\mu-\rho\|_1=2B_g\operatorname{TV}(\mu,\rho)$.  Concatenating heads gives squared norm bounded by $\sum_gH_g(\epsilon_g+2B_g\xi_g)^2$, and applying $W_o$ gives the span bound.
\end{proof}

\begin{remark}[Mechanistic bound meaning]
\label{rem:mechanistic-bound-meaning}
The bound is an error-propagation result conditional on a chosen reference family, coupling, atom error, transport error, and norm bounds.  It is not a decomposition of perplexity into independent causes.
\end{remark}

\begin{corollary}[Conditional loss stability]
\label{cor:loss-sensitivity-pooling}
Let $Q_\theta(h,\sigma)$ denote the single-token cross-entropy loss obtained
from logits $W_{\rm lm}(h+\sigma)$.  If this readout loss is locally Lipschitz
in span with constant $L_{\rm model}$ on a ball containing the implemented and
reference spans, then
\begin{equation}
|Q_\theta(h_t^{(0)},\operatorname{span}_t)-Q_\theta(h_t^{(0)},\operatorname{span}_{*,t})|
\le L_{\rm model}\|\Delta\operatorname{span}_t\|.
\end{equation}
Any comparison to a different reference loss additionally requires the reference-family Lipschitz and calibration residual assumptions.
\end{corollary}
\begin{proof}
This is the definition of local Lipschitz continuity applied to the two spans.  A second loss family is controlled only after adding the usual triangle-inequality terms for its own perturbation and the calibration residual at the reference span.
\end{proof}

\begin{theorem}[Pooling collision and recovery boundary]
\label{thm:pooling-collision-recovery}
If two histories with the same current token and position induce identical multigroup processed atoms, descriptors, fibers, and router-query inputs through time $t$, then every deterministic downstream stack/router/readout gives the same span and logits.  Moreover, a continuous pre-stack map from an open subset of $\mathbb R^{LD}$ into $\prod_g\mathbb R^{M_gD_g}$ has no global continuous left inverse on an open set whenever $\sum_gM_gD_g<LD$.
\end{theorem}
\begin{proof}
The first claim is determinism: equal inputs to the downstream maps give equal outputs, and equal current token and position give equal anchors.  For the second claim, a continuous left inverse would make the pre-stack map a continuous injection from an open subset of $\mathbb R^{LD}$ into a lower-dimensional Euclidean space, contradicting invariance of domain and the standard dimension obstruction.
\end{proof}

\begin{theorem}[Discrete interior allocation]
\label{thm:conditional-interior-allocation}
Let $A(n)=(H-n)M_f^2+nM_c^2$ and $E(n)$ be an abstract error for $n$ coarse heads.  If $M_c<M_f$, then $A(n+1)-A(n)<0$.  If $G(n)=E(n-1)-E(n)$ is nonincreasing, $G(1)>0$, and $G(H)<0$, then $E$ has a minimizer in $\{1,\ldots,H-1\}$.
\end{theorem}
\begin{proof}
The memory difference is $M_c^2-M_f^2<0$.  Since $G(1)>0$, $E(1)<E(0)$, so $0$ is not a minimizer.  Since $G(H)<0$, $E(H)>E(H-1)$, so $H$ is not a minimizer.  A finite set has a minimizer, and neither endpoint can be one.
\end{proof}

\subsection{Tier C Empirical Propositions and Conjectures}
\label{sec:mrp6-tier-c}

\begin{proposition}[Effective support identities]
\label{prop:effective-support-bounds}
For any pooling law with weights $\omega_{j,m}^g$ on a group set $S_m^g$,
\begin{equation}
n_{\rm eff}^{m,g}=\frac{1}{\sum_{j\in S_m^g}(\omega_{j,m}^g)^2},
\qquad
1\le n_{\rm eff}^{m,g}\le |S_m^g|.
\end{equation}
\end{proposition}
\begin{proof}
The upper bound follows from Cauchy-Schwarz, $(\sum_j\omega_j)^2\le |S|\sum_j\omega_j^2$, and the lower bound from $\sum_j\omega_j^2\le\sum_j\omega_j=1$.
\end{proof}

\begin{proposition}[Pooling concentration regimes]
\label{prop:pooling-concentration-regimes}
For the pure Boltzmann factor on a fixed finite set, as $\tau_{\rm pool}\to0^+$ the law concentrates on minimum-energy tokens; as $\tau_{\rm pool}\to\infty$ it becomes uniform over finite-energy tokens.  The implemented soft-trimmed rule has the same Boltzmann factor multiplied by a trimming gate, so its high-temperature limit is the normalized trimming gate, not necessarily the full uniform law.
\end{proposition}
\begin{proof}
Both limits are the standard finite softmax limits.  Multiplication by a positive trimming gate changes only the limiting base measure after renormalization.
\end{proof}

\begin{definition}[Current feasible operating region]
\label{def:feasible-operating-region}
A current-model operating region is a fixed control tuple together with group-local nonempty fibers, noncollapsed pooling diagnostics, bounded routed approximation quantities $(\epsilon_g,\xi_g,B_g)$, and local readout stability constants sufficient to make Theorem~\ref{thm:mechanistic-decomposition} and Corollary~\ref{cor:loss-sensitivity-pooling} small.  It is a diagnostic definition, not a universal generalization or perplexity theorem.
\end{definition}

\begin{corollary}[Joint experimental design]
\label{cor:joint-experimental-design}
Empirical specialization must vary or measure bank topology, blur allocation, pooling concentration, routing diagnostics, memory counts, and task loss inside a fixed control tuple.  Rank, entropy, or memory alone cannot select b25 or prove superiority over token attention.
\end{corollary}
\begin{proof}
The exact results control structural support, rank, and memory; the conditional results require approximation, transport, and stability quantities.  None of the structural quantities contains the validation loss function or the data distribution.
\end{proof}

\begin{remark}[What is proven]
\label{rem:what-is-proven}
The appendix proves causal closure, contextual-path factorization, group-local routing entropy, direct-sum routing capacity, exact dense score-memory counts, conditional routed approximation, conditional loss stability, a recovery boundary, and a discrete interior-allocation existence theorem.  It does not prove empirical specialization, perplexity superiority, token-attention equivalence, subquadratic complexity, or an intrinsic maximum feasible context length.
\end{remark}

\subsection{Limitations and Nonclaims}
\label{sec:mrp6-limitations}

The allocation theorem is conditional on marginal error gains and does not identify a blur optimum.  The completed MRP-3 MQAR probe did not reach the support accuracy regime, so empirical specialization remains unestablished.

applied after token and positional embeddings and before bank pooling. This module was disabled in the experiments emphasized in the main paper and was not part of the topology, temperature, pooling, dense, sparse, or linear family sweeps. Preliminary checks with the module enabled did not materially change the qualitative behavior of the model, so it is treated as an implementation extension rather than a core architectural component.
